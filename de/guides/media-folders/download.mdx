Manchmal brauchst du ein Foto wieder auf deinem Computer, etwa um es an einen Kunden zu schicken oder erneut zu bearbeiten. Du kannst das hochgeladene Original herunterladen oder die kleinere Version, die Shootstack daraus für das Web erstellt hat.

## Ein Foto herunterladen

Klicke mit der rechten Maustaste auf das Foto oder klicke auf **⋯** auf seiner Karte und wähle **Herunterladen**. Wenn das Foto in der Fotoansicht geöffnet ist, klicke dort auf **Herunterladen**.

<Note>
Du kannst jeweils ein Foto herunterladen. Lade mehrere Fotos daher einzeln herunter. Du kannst sie weiterhin als Gruppe kopieren, verschieben oder löschen.
</Note>

## Die Datei auswählen

<Steps>
  <Step title="Eine Version auswählen">
    Lass unter **Fotodatei auswählen** die Option **Für das Web optimierte Fotodatei** ausgewählt, wenn du die kleinere Version fürs Web möchtest. Für die hochgeladene Datei in voller Größe klicke auf **Originaldatei des Fotos**. Beide Optionen zeigen Dateinamen und Dateigröße.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/download-choose-1.webp" alt="Dialog Foto herunterladen mit ausgewählter Option Für das Web optimierte Fotodatei" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/download-choose-1-dark.webp" alt="Dialog Foto herunterladen mit ausgewählter Option Für das Web optimierte Fotodatei" />
    </Frame>
  </Step>
  <Step title="Das Foto herunterladen">
    Klicke auf **Foto herunterladen**. Auf dem Smartphone öffnet sich das Teilen-Menü, in dem du das Foto speichern kannst.
  </Step>
</Steps>

## Wenn ein Download blockiert wird

Dein Tarif enthält ein monatliches Downloadvolumen. Ist es aufgebraucht, werden Downloads pausiert, bis der nächste Monat beginnt.

<Note>
Wenn der Dialog **Foto herunterladen** meldet, dass dein Downloadvolumen für diesen Monat aufgebraucht ist, warte bis zum nächsten Monat oder wechsle zu einem höheren Tarif, um weiter herunterzuladen.
</Note>
