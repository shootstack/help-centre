description: 'Preview help center changes locally'
---

<Info>**Prerequisites**: - Node.js version 20.17 or higher - Mintlify CLI (`npm i -g mint`)</Info>

<Steps>
<Step title="Install the Mintlify CLI">

```bash
npm i -g mint
```

</Step>

<Step title="Preview locally">

From the repository root:

```bash
npm run dev
```

The help center preview runs at `http://localhost:3333`.

<Note>
    Port **3333** avoids conflicts with `diamond-app` (**3000**) and `diamond-site` (**3001**). Internal API docs use
    **3334** in `diamond-docs/`.
</Note>

</Step>
</Steps>

## Validate

```bash
npm run validate
npm run broken-links
```

## Update the CLI

```bash
mint update
```
