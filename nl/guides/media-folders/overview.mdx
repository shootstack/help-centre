In een media map staan de foto’s voor een shoot. De meeste fotografen maken voor elke set een aparte map, bijvoorbeeld voor proeffoto’s en definitief bewerkte foto’s. Zo kan een galerij je klanten precies de foto’s laten zien die voor hen bedoeld zijn.

## Waar je media mappen vindt

Media mappen horen bij een project. Open het project en ga naar het tabblad **Inhoud**. Klik in de linkerzijbalk op **Media mappen** om elke map als kaart te bekijken.

## Een media map maken

Maak een nieuwe map wanneer je een set foto’s bij elkaar wilt houden, bijvoorbeeld de proeffoto’s van een shoot.

<Steps>
  <Step title="Open Media mappen">
    Op het tabblad **Inhoud** van je project klik je in de linkerzijbalk op **Media mappen**.
  </Step>
  <Step title="Start een nieuwe media map">
    Klik op **Nieuw**. Heeft het project nog geen mappen, klik dan op **Map aanmaken**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-create-1.webp" alt="Bovenkant van de pagina Media mappen met de knop Nieuw" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-create-1-dark.webp" alt="Bovenkant van de pagina Media mappen met de knop Nieuw" />
    </Frame>
  </Step>
  <Step title="Geef de media map een naam">
    Vul bij **Naam** een naam in waaraan je de map later herkent, bijvoorbeeld de set of de datum.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-create-2.webp" alt="Venster Media map aanmaken met Naam, Watermerk (optioneel) en Handmatig sorteren inschakelen" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-create-2-dark.webp" alt="Venster Media map aanmaken met Naam, Watermerk (optioneel) en Handmatig sorteren inschakelen" />
    </Frame>
  </Step>
  <Step title="Kies een watermerk">
    Kies bij **Watermerk (optioneel)** een watermerk als het om proeffoto’s gaat. Je klanten kunnen ze in een galerij bekijken, maar niet downloaden. Laat het veld leeg voor de definitieve foto’s.
  </Step>
  <Step title="Maak de media map">
    Klik op **Map aanmaken**. De nieuwe map verschijnt aan het einde van het raster, klaar voor je foto’s.
  </Step>
</Steps>

**Handmatig sorteren inschakelen** staat aan voor nieuwe mappen, zodat je de foto’s in je eigen volgorde kunt slepen.

Een map met handmatig sorteren kan maximaal 500 foto’s bevatten. Bekijk [Foto’s sorteren](/nl/guides/media-folders/sort).

<Note>
Een project kan maximaal 25 media mappen bevatten.
</Note>

## Een media map openen

Klik op de mapkaart of op de map in de linkerzijbalk. Je kunt ook met de rechtermuisknop op de map klikken en **Openen** kiezen.

## De naam van een media map wijzigen

Klik met de rechtermuisknop op de mapkaart. Of beweeg je muis over de map in de zijbalk en klik op **⋯**.

<Steps>
  <Step title="Kies Naam wijzigen">
    Klik in het mapmenu op **Naam wijzigen**.
  </Step>
  <Step title="Vul de nieuwe naam in">
    Vul de nieuwe naam in en klik daarna op **Mapnaam wijzigen naar** om te bevestigen.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-rename-1.webp" alt="Venster Opties met de mapnaam en Mapnaam wijzigen naar" />

    </Frame>
  </Step>
</Steps>

## Een media map dupliceren

Met dupliceren maak je een tweede map met dezelfde foto’s, bijvoorbeeld een kopie met watermerk voor proeffoto’s.

<Steps>
  <Step title="Kies Dupliceren">
    Klik in het mapmenu op **Dupliceren**.
  </Step>
  <Step title="Geef de kopie een naam">
    Vul bij **Naam** een naam voor de nieuwe map in.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-duplicate-1.webp" alt="Venster Media map dupliceren met een leeg veld Naam en Watermerk" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-duplicate-1-dark.webp" alt="Venster Media map dupliceren met een leeg veld Naam en Watermerk" />
    </Frame>
  </Step>
  <Step title="Kies een watermerk">
    Kies bij **Watermerk** een watermerk voor de kopie of laat het veld leeg.
  </Step>
  <Step title="Dupliceer de map">
    Klik op **Map dupliceren**. Shootstack kopieert de foto’s naar de nieuwe map, die aan het einde van het raster verschijnt.
  </Step>
</Steps>

<Note>
Je kunt een map met maximaal 500 foto’s dupliceren. Maak voor een grotere map een nieuwe map en [kopieer de foto’s](/nl/guides/media-folders/organize) in een paar rondes.
</Note>

## Een media map verwijderen

<Warning>
Als je een media map verwijdert, worden ook alle foto’s in de map verwijderd. Dit kun je niet ongedaan maken.
</Warning>

<Steps>
  <Step title="Open het mapmenu">
    Klik met de rechtermuisknop op de mapkaart. Of beweeg je muis over de map in de zijbalk en klik op **⋯**.
  </Step>
  <Step title="Kies Verwijderen">
    Klik op **Verwijderen**.
  </Step>
  <Step title="Bevestig">
    Klik in **Map verwijderen** op **Verwijderen**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-delete-1.webp" alt="Venster Map verwijderen met de waarschuwing en de knop Verwijderen" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-delete-1-dark.webp" alt="Venster Map verwijderen met de waarschuwing en de knop Verwijderen" />
    </Frame>
  </Step>
</Steps>

## Binnen een media map

- [Foto’s uploaden](/nl/guides/media-folders/upload): voeg foto’s vanaf je computer toe.
- [Foto’s sorteren](/nl/guides/media-folders/sort): zet ze in de volgorde waarin je klanten ze moeten zien.
- [Foto’s bekijken](/nl/guides/media-folders/view): zoek een foto en bekijk de bestandsdetails.
- [Foto’s downloaden](/nl/guides/media-folders/download): sla een bestand weer op je computer op.
- [Foto’s organiseren](/nl/guides/media-folders/organize): kopieer, verplaats of verwijder foto’s.

Je klanten zien een media map nooit rechtstreeks. Voeg de map toe aan een galerij en stuur de galerij daarna met een galerijlink naar je klanten.
