Voeg media mappen toe aan een galerij om te bepalen welke foto’s je klant ziet. De foto’s blijven in hun map, dus je hoeft geen tweede kopie te uploaden.

## Een media map toevoegen

<Steps>
  <Step title="Open de mappenlijst">
    Klik in de werkbalk van de galerij op **Media map**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/galleries/folders-add-1.webp" alt="Werkbalk van de galerij met de knop Media map" />
      <img className="hidden dark:block" src="/assets/images/guides/galleries/folders-add-1-dark.webp" alt="Werkbalk van de galerij met de knop Media map" />
    </Frame>
  </Step>
  <Step title="Open de mappen van het project">
    Klik onderaan de lijst op **Media map**. Zoek in **Zoek map...** als het project veel mappen heeft.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/galleries/folders-add-2.webp" alt="Mappenlijst met Media map onderaan en een menu met projectmappen" />
      <img className="hidden dark:block" src="/assets/images/guides/galleries/folders-add-2-dark.webp" alt="Mappenlijst met Media map onderaan en een menu met projectmappen" />
    </Frame>
  </Step>
  <Step title="Voeg de map toe">
    Klik op de map om die met de foto’s aan de lijst toe te voegen. Mappen die al in de galerij staan, verschijnen niet in het menu.
  </Step>
</Steps>

Lees in [Media mappen](/nl/guides/media-folders/overview) hoe je het watermerk van een map wijzigt.

De cover blijft leeg totdat je een map toevoegt. Zie [De cover instellen](/nl/guides/galleries/cover).

## De volgorde van media mappen wijzigen

Sleep een map in de lijst omhoog of omlaag om je klanten de ene fotoset vóór de andere te laten zien. De galerij bewaart de nieuwe volgorde.

## Een media map verwijderen

Beweeg je muis over de rij van de map en klik op de X aan het einde. De media map en de foto’s blijven in het project.

<Frame>
  <img className="dark:hidden block" src="/assets/images/guides/galleries/folders-remove-1.webp" alt="Rij van een media map met een X aan het einde" />
  <img className="hidden dark:block" src="/assets/images/guides/galleries/folders-remove-1-dark.webp" alt="Rij van een media map met een X aan het einde" />
</Frame>

## Als de galerij vol is

<Note>
Een galerij kan maximaal 10 media mappen bevatten. Verwijder een map voordat je er een toevoegt.
</Note>

<Note>
Een galerij kan maximaal 100 GB aan media mappen bevatten. Laat een map weg als je daardoor boven de 100 GB zou komen.
</Note>

Zie je **Opslaglimiet voor galerij bereikt**, klik dan op **OK**.
