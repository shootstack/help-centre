A color palette brings your photography business's colors into your galleries. Create one before designing a gallery, then reuse it for other shoots.

## Create a color palette

Each palette has three colors:

- **Brand color** is for buttons, links, and highlights.
- **Cover color** is the background of the cover section.
- **Cover text color** is for text on gallery covers.

<Steps>
  <Step title="Open branding settings">
    Click the workspace name at the top of the app sidebar, then choose **Branding settings**.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/branding-settings/color-palettes-create-1.webp" alt="Workspace menu with Branding settings" />
      <img className="hidden dark:block" src="/assets/images/guides/branding-settings/color-palettes-create-1-dark.webp" alt="Workspace menu with Branding settings" />
    </Frame>
  </Step>
  <Step title="Start a palette">
    Click **Color palettes**, then **Create color palette**.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/branding-settings/color-palettes-create-2.webp" alt="Color palettes tab with the Create color palette button" />
      <img className="hidden dark:block" src="/assets/images/guides/branding-settings/color-palettes-create-2-dark.webp" alt="Color palettes tab with the Create color palette button" />
    </Frame>
  </Step>
  <Step title="Name the palette">
    In **Name**, enter a name you'll recognize when choosing colors for a gallery.
  </Step>
  <Step title="Choose the colors">
    Open each color field and choose a color with the picker, or type a color code.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/branding-settings/color-palettes-create-3.webp" alt="Create color palette dialog with Name and three color fields, with the Brand color picker open" />
      <img className="hidden dark:block" src="/assets/images/guides/branding-settings/color-palettes-create-3-dark.webp" alt="Create color palette dialog with Name and three color fields, with the Brand color picker open" />
    </Frame>
  </Step>
  <Step title="Create the palette">
    Click **Create color palette**. The new palette appears in the list, ready to use in a gallery.
  </Step>
</Steps>

<Note>
A workspace holds up to 10 custom color palettes. Built-in palettes don't count toward this limit. At the limit, edit an existing palette or delete an unused one before creating another.
</Note>

## Edit a color palette

You can change a custom palette's name and colors. Built-in palettes stay as they are.

<Steps>
  <Step title="Open the palette menu">
    Right-click the palette row, or click **⋯** on it.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/branding-settings/color-palettes-edit-1.webp" alt="Custom color palette row with Open, Edit, and Delete in its menu" />
      <img className="hidden dark:block" src="/assets/images/guides/branding-settings/color-palettes-edit-1-dark.webp" alt="Custom color palette row with Open, Edit, and Delete in its menu" />
    </Frame>
  </Step>
  <Step title="Change the palette">
    Choose **Edit**, then change the name or colors.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/branding-settings/color-palettes-edit-2.webp" alt="Update color palette dialog with Name and three color fields" />
      <img className="hidden dark:block" src="/assets/images/guides/branding-settings/color-palettes-edit-2-dark.webp" alt="Update color palette dialog with Name and three color fields" />
    </Frame>
  </Step>
  <Step title="Save your changes">
    Click **Update color palette**.
  </Step>
</Steps>

## Use a palette in a gallery

Choose the palette in a gallery's **Design settings**. See [Design a gallery](/guides/galleries/design).

## Delete a color palette

<Warning>
Deleting a color palette removes it from your workspace. This can't be undone.
</Warning>

<Steps>
  <Step title="Open the palette menu">
    Right-click the palette row, or click **⋯** on it.
  </Step>
  <Step title="Choose Delete">
    Click **Delete**.
  </Step>
  <Step title="Confirm">
    In **Delete color palette**, click **Delete**.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/branding-settings/color-palettes-delete-1.webp" alt="Delete color palette dialog with the palette name and Delete button" />
      <img className="hidden dark:block" src="/assets/images/guides/branding-settings/color-palettes-delete-1-dark.webp" alt="Delete color palette dialog with the palette name and Delete button" />
    </Frame>
  </Step>
</Steps>
