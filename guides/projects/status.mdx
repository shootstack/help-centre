A status tells you where a shoot stands. Set it on each project, then use the filter and sort controls on **Projects** to pull up the ones you need.

## Set a project's status

You can pick **No status**, **Todo**, **In progress**, or **Done**. For example, use **Todo** once the shoot is booked, **In progress** while you edit, and **Done** when the gallery is delivered.

<Steps>
  <Step title="Open the project menu">
    On **Projects**, open the **⋯** menu on the project card. Inside a project, open the **⋯** menu next to the project name.
  </Step>
  <Step title="Choose a status">
    Click **Status**, then pick one. It saves as soon as you choose it.

The status shows as an icon on the project card, so you can scan the grid without opening anything.

## Filter projects

For example, show only the shoots that are still **In progress**.

<Steps>
  <Step title="Open the filter">
    On **Projects**, click **Filter** in the toolbar.
    {/* TODO screenshot: Projects toolbar with Filter highlighted
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/projects/status-filter-1.png" alt="Projects toolbar with the Filter button" />
      <img className="hidden dark:block" src="/assets/images/guides/projects/status-filter-1-dark.png" alt="Projects toolbar with the Filter button" />
    </Frame>
    */}
  </Step>
  <Step title="Choose what to show">
    Choose **Status**, then one or more statuses. The grid shows only matching projects. You can also filter by **Is favorite**, **Created At**, or **Updated At**. The date filters let you pick a period such as **This week** or **This month**.
  </Step>
  <Step title="Clear the filter">
    Click **Clear filters** to see every project again.
  </Step>
</Steps>

## Sort projects

Projects show newest first. To change the order, click **Sorted by** in the toolbar and choose **Name**, **Last updated**, or **Creation date**. Then pick **Ascending** or **Descending**. **Last updated** is handy for getting back to whatever you worked on last.
