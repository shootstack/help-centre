Keep a contract, brief, or other document with the contact it belongs to. Open the contact, then click **Files**.

## Upload files

<Steps>
  <Step title="Start an upload">
    Click **Upload**. If the contact has no files yet, click **Upload files** instead.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/contacts/files-upload-1.webp" alt="Contact Files header with the Upload button" />
      <img className="hidden dark:block" src="/assets/images/guides/contacts/files-upload-1-dark.webp" alt="Contact Files header with the Upload button" />
    </Frame>
  </Step>
  <Step title="Add your files">
    Drag your files onto the area that says **Drag and drop files here**, or click **Upload file** to pick them from your computer.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/contacts/files-upload-2.webp" alt="Upload files screen with the drop area and Upload file button" />
      <img className="hidden dark:block" src="/assets/images/guides/contacts/files-upload-2-dark.webp" alt="Upload files screen with the drop area and Upload file button" />
    </Frame>
  </Step>
  <Step title="Let the upload finish">
    Each file shows its progress. When they're all done, close the upload screen.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/contacts/files-upload-3.webp" alt="Upload files list showing files uploading and finished" />
      <img className="hidden dark:block" src="/assets/images/guides/contacts/files-upload-3-dark.webp" alt="Upload files list showing files uploading and finished" />
    </Frame>
  </Step>
</Steps>

If you need to stop partway, click **Cancel upload**. Shootstack checks each file after upload, and it's ready within seconds.

## File types and size

Shootstack accepts PDF, DOC, DOCX, Pages, XLS, XLSX, Numbers, Keynote, PPTX, TXT, CSV, ZIP, JPG, PNG, WEBP, GIF, and HEIC.

<Note>
Each file can be up to 25 MB. You can upload up to 20 files at a time. For a bigger set, upload it in a few rounds.
</Note>

## When an upload is blocked

If your contact file storage is full, free up space by deleting files you no longer need, or upgrade your plan.

## Download a file

Right-click the file, or click **⋯** on its row, then click **Download**. In **Download file**, click **Download**.

<Frame>
  <img className="dark:hidden block" src="/assets/images/guides/contacts/files-download-1.webp" alt="Contact file row menu with the Download option" />
  <img className="hidden dark:block" src="/assets/images/guides/contacts/files-download-1-dark.webp" alt="Contact file row menu with the Download option" />
</Frame>

## When a download is blocked

Your plan includes a monthly amount of download bandwidth. Once it's used up, downloads pause until the next month starts.

<Note>
If **Download file** says this month's bandwidth is used up, wait until next month or upgrade your plan to keep downloading.
</Note>

## Rename a file

Right-click the file, or click **⋯** on its row, then click **Rename**. Type the new name, then click **Rename file to** to confirm.

## Delete a file

<Warning>
Deleting a file removes it from Shootstack. This can't be undone.
</Warning>
