Add media folders to a gallery to choose which photos your client sees. The photos stay in their folder, so you don't upload a second copy.

## Add a media folder

<Steps>
  <Step title="Open the folder list">
    On the gallery toolbar, click **Media folder**. If the gallery already has folders, the button shows how many.
    {/* TODO screenshot: Open gallery toolbar with Media folder highlighted
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/galleries/folders-add-1.png" alt="Gallery toolbar with the Media folder button" />
      <img className="hidden dark:block" src="/assets/images/guides/galleries/folders-add-1-dark.png" alt="Gallery toolbar with the Media folder button" />
    </Frame>
    */}
  </Step>
  <Step title="Open this project's folders">
    Click **Media folder** at the bottom of the list. Type in **Search folder...** if the project has many folders.
    {/* TODO screenshot: Folder list with Media folder and the project folder menu
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/galleries/folders-add-2.png" alt="Folder list with Media folder at the bottom and a menu of project folders" />

  <Step title="Add the folder">
    Click the folder. It appears in the list with its photos. Folders already in the gallery don't show in the menu.

</Steps>

A watermarked folder shows a different folder icon. To change the watermark, see [Media folders](/guides/media-folders/overview).

The cover stays empty until you add a folder. See [Set the cover](/guides/galleries/cover).

## When the gallery is full

<Note>
A gallery holds up to 10 media folders. Remove one before you add another.
</Note>

<Note>
A gallery holds up to 100 GB of media folders. Leave out a folder that would take it past 100 GB.
</Note>

If you see **Gallery storage limit reached**, click **OK**.
