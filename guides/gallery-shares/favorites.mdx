Your client can mark the photos they like in a gallery share. Review their picks, then copy them into a media folder. Pinning a project is different. See [Favorites](/guides/projects/favorites).

## Allow favorites

A new share already lets clients mark the photos they like.

<Steps>
  <Step title="Open favorites settings">
    On the share's **Info** tab, open **Favorites settings**. The **Favorites** step of **Create link** has the same switches.
    {/* TODO screenshot: Info tab with Favorites settings open
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/gallery-shares/favorites-allow-1.png" alt="Gallery share Info tab with Favorites settings open and Allow photo favorites" />
      <img className="hidden dark:block" src="/assets/images/guides/gallery-shares/favorites-allow-1-dark.png" alt="Gallery share Info tab with Favorites settings open and Allow photo favorites" />
    </Frame>
    */}
  </Step>
  <Step title="Leave favorites on">
    Leave **Allow photo favorites** on so your client can click **Add to favorites** on a photo. Turn it off if they should only look.
  </Step>
</Steps>

## Set a favorites limit

Set a cap when you want a short list, such as the client's top photos from a proof gallery.

<Steps>
  <Step title="Turn on the limit">
    Turn on **Photo favorites limit**. If you don't see it, turn on **Allow photo favorites** first.
    {/* TODO screenshot: Photo favorites limit on with the number field
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/gallery-shares/favorites-limit-1.png" alt="Favorites settings with Photo favorites limit on and Favorites limit set to 25" />
      <img className="hidden dark:block" src="/assets/images/guides/gallery-shares/favorites-limit-1-dark.png" alt="Favorites settings with Photo favorites limit on and Favorites limit set to 25" />
    </Frame>
    */}
  </Step>
  <Step title="Enter the number">
    On **Info**, enter the most photos a client can pick in **Favorites limit**. It starts at 25.
  </Step>
</Steps>

<Note>
A client can favorite up to 500 photos on a share, even with **Photo favorites limit** off. For a smaller cap, enter a number from 1 to 500.
</Note>

## Review favorite photos

<Steps>
  <Step title="Open the list">
    On the gallery share, open the **Favorites** tab.

## Copy favorites to a folder

<Steps>
  <Step title="Open the menu">
    On the **Favorites** tab, click **⋯** next to **Favorite photos**.
    {/* TODO screenshot: Favorite photos toolbar with the menu open
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/gallery-shares/favorites-copy-1.png" alt="Favorite photos toolbar menu with Copy to folder" />
      <img className="hidden dark:block" src="/assets/images/guides/gallery-shares/favorites-copy-1-dark.png" alt="Favorite photos toolbar menu with Copy to folder" />
    </Frame>
    */}
  </Step>
  <Step title="Choose Copy to folder">
    Click **Copy to folder**.
  </Step>
  <Step title="Name the folder">
    In **Copy to folder**, type a folder name in **Name**, such as Client picks.
    {/* TODO screenshot: Copy to folder dialog with Name
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/gallery-shares/favorites-copy-2.png" alt="Copy to folder dialog with the Name field and Copy to folder" />
      <img className="hidden dark:block" src="/assets/images/guides/gallery-shares/favorites-copy-2-dark.png" alt="Copy to folder dialog with the Name field and Copy to folder" />
    </Frame>
    */}
  </Step>
  <Step title="Copy the photos">
    Click **Copy to folder**. Shootstack creates a media folder in the project with every favorite from the share.
  </Step>
</Steps>

<Note>
A project holds up to 25 media folders. If the project is full, delete a folder you no longer need, then copy again. See [Media folders](/guides/media-folders/overview).
</Note>
