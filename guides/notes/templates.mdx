A note template holds text you reuse, such as a shot list or questionnaire, so you don't retype it for every shoot. Create it once on **Templates**, then insert it into an empty note when you need it.

## Create a template

<Steps>
  <Step title="Open Templates">
    In the workspace menu, click **Notes**, then open the **Templates** tab.
  </Step>
  <Step title="Start a new template">
    Click **New**. If the workspace has no templates yet, click **Create template** instead. A template card appears on the list.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/templates-create-1.png" alt="Templates page header with the New button" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/templates-create-1-dark.png" alt="Templates page header with the New button" />
    </Frame>
  </Step>
</Steps>

On **Templates**, click the search icon in the header or press **/**, then type at least two characters.

<Frame>
  <img className="dark:hidden block" src="/assets/images/guides/notes/templates-create-2.png" alt="Templates search with the Search template field" />
  <img className="hidden dark:block" src="/assets/images/guides/notes/templates-create-2-dark.png" alt="Templates search with the Search template field" />
</Frame>

## Open a template

Click a template card to open **Edit template**. Or click **⋯** on the card or right-click it, then choose **Open**.

A template has a title and body. Format the body like a note. The body holds up to 3000 characters of text; shorten it if you reach the limit. See [Write a note](/guides/notes/write).

<Frame>
  <img className="dark:hidden block" src="/assets/images/guides/notes/templates-open-1.png" alt="Edit template dialog with the title and body" />
  <img className="hidden dark:block" src="/assets/images/guides/notes/templates-open-1-dark.png" alt="Edit template dialog with the title and body" />
</Frame>

The list starts sorted by **Creation date** in **Descending** order. Click **Sorted by** to change it. Choose a field:

- **Title**
- **Last updated**
- **Creation date**

Then pick **Ascending** or **Descending**.

## Insert a template

**Insert note template** only shows when the note body is empty.

<Steps>
  <Step title="Open an empty note">
    Open a note that has no body yet.
  </Step>
  <Step title="Choose a template">
    Under **Note templates**, click **Insert note template**, then pick a template. Shootstack fills the empty body.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/templates-insert-1.png" alt="Edit note with Insert note template under Note templates" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/templates-insert-1-dark.png" alt="Edit note with Insert note template under Note templates" />
    </Frame>
  </Step>
</Steps>

## Save a note as a template

Turn a finished note into a template you can reuse on the next shoot.

<Steps>
  <Step title="Open the note">
    Open the note you want to save.
  </Step>
  <Step title="Start saving as a template">
    Under **Note templates**, click **Save as note template**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/templates-save-1.png" alt="Edit note with Save as note template under Note templates" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/templates-save-1-dark.png" alt="Edit note with Save as note template under Note templates" />
    </Frame>
  </Step>
  <Step title="Edit the title and content">
    In **Save note template**, the fields start with the note's title and body. Change **Title** or **Content** if you want different text.
  </Step>
  <Step title="Save the template">
    Click **Save template**.
  </Step>
</Steps>

## Delete a template

<Warning>
Deleting a template removes it from your workspace. This can't be undone.
</Warning>

<Steps>
  <Step title="Open the template menu">
    On **Templates**, open the **⋯** menu on the card, or right-click the card.
  </Step>
  <Step title="Choose Delete">
    Click **Delete**.
  </Step>
  <Step title="Confirm">
    In **Delete note template**, click **Delete**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/templates-delete-1.png" alt="Delete note template dialog with the Delete button" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/templates-delete-1-dark.png" alt="Delete note template dialog with the Delete button" />
    </Frame>
  </Step>
</Steps>
