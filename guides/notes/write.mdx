Open a note and write the body, such as a shot list, client request, or delivery notes you can hand over later.

## Format the note

In **Edit note**, click **Start typing your note...** to write.

Use the toolbar to choose a text size:

- **Title**
- **Heading**
- **Subheading**
- **Body**

The icon buttons let you bold, italicize, underline, or strikethrough text; undo or redo; add an emoji; or insert a line break.

A note holds up to 3000 characters of text. Formatting can count toward the limit even when the counter doesn't show it. If you reach the limit, shorten or simplify the note.
</Note>

## Add a link

<Steps>
  <Step title="Open the link tool">
    In the toolbar, click the link icon.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/write-link-1.webp" alt="Edit note with the Link popover open" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/write-link-1-dark.webp" alt="Edit note with the Link popover open" />
    </Frame>
  </Step>
  <Step title="Enter the link">
    In **Link**, type the URL in **Enter link URL**. You can add text in **Enter link text (optional)**.
  </Step>
  <Step title="Add the link">
    Click **Insert**. If you already selected a link, click **Update**.
  </Step>
</Steps>

## Add a list

In the toolbar, open the list menu. Choose **Bullet list** or **Numbered list**. For a checklist, choose **Checklist**. Choose **None** to turn the list off.

## Export a PDF

In the footer of **Edit note**, click **Export PDF**. The download starts right away.

The file uses the note title, or `note.pdf` when the title is empty. If the note has a project or contact, the PDF shows it.
