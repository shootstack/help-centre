## Skip or replace duplicates

A duplicate is a file with the same name as a photo already in this folder. Shootstack skips duplicates by default, so you can't upload a set twice by accident. Choose replace when you've re-edited photos and want the new versions to take over.

<Steps>
  <Step title="Open duplicate options">
    On the **Upload photos** screen, click **Skip duplicates**.
    {/* TODO screenshot: Skip duplicates menu with Skip and Replace
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/upload-duplicates-1.png" alt="Upload photos header with the Skip duplicates menu open" />

    </Frame>

  <Step title="Choose skip or replace">
    Click **Skip** to keep the photos already in the folder, or **Replace** to overwrite them with the new files. Do this before you add the photos.

</Steps>

## File types and size

Shootstack accepts JPEG, PNG, and WebP files.

<Note>
Each file can be up to 100 MB.
</Note>

If a file can't be uploaded, Shootstack flags it and tells you why. Usually it's the wrong file type or a file over 100 MB.

## When an upload is blocked

Sometimes the folder or your storage is full. Shootstack tells you on the **Upload photos** screen.

<Note>
A folder with **Manual sorting** holds up to 500 photos, and a folder with **Auto sorting** holds up to 2,500. For a large shoot, switch the folder to auto sorting or split the photos across folders. See [Sort photos](/guides/media-folders/sort).
</Note>

If your photo storage is full, free up space by deleting photos you no longer need, or upgrade your plan.
