A media folder is where the photos for a shoot live. Most photographers create one folder per set, such as proofs and final edits, so a gallery can show clients exactly the photos they should see.

## Where media folders live

Media folders belong to a project. Open the project and go to the **Content** tab. Click **Media folders** in the left sidebar to see each folder as a card.

## Create a media folder

Start a new folder whenever you have a set of photos to keep together, such as the proofs from a shoot.

<Steps>
  <Step title="Open Media folders">
    On the project's **Content** tab, click **Media folders** in the left sidebar.
  </Step>
  <Step title="Start a new media folder">
    Click **New**. If the project has no folders yet, click **Create folder** instead.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-create-1.png" alt="Media folders page header with the New button" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-create-1-dark.png" alt="Media folders page header with the New button" />
    </Frame>
  </Step>
  <Step title="Name the media folder">
    In **Name**, enter a name you'll recognize later, such as the set or the date.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-create-2.png" alt="Create media folder dialog with Name, Watermark (optional), and Enable manual sorting" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-create-2-dark.png" alt="Create media folder dialog with Name, Watermark (optional), and Enable manual sorting" />
    </Frame>
  </Step>
  <Step title="Choose a watermark">
    Under **Watermark (optional)**, pick a watermark if these are proofing photos. Your clients can view them in a gallery but can't download them. Leave it empty for final photos.
  </Step>
  <Step title="Create the media folder">
    Click **Create folder**. The new folder appears at the end of the grid, ready for your photos.
  </Step>
</Steps>

**Enable manual sorting** is on for new folders, so you can drag photos into your own order.

A folder with manual sorting holds up to 500 photos. See [Sort photos](/guides/media-folders/sort).

<Note>
A project holds up to 25 media folders.
</Note>

## Open a media folder

Click the folder card, or click the folder in the left sidebar. You can also right-click the folder and choose **Open**.

## Rename a media folder

To open the folder menu, right-click the folder card, or hover the folder in the sidebar and click **⋯**.

<Steps>
  <Step title="Choose Rename">
    In the folder menu, click **Rename**.
  </Step>
  <Step title="Enter the new name">
    Type the new name, then click **Rename folder to** to confirm.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-rename-1.png" alt="Options dialog with the folder name and Rename folder to" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-rename-1-dark.png" alt="Options dialog with the folder name and Rename folder to" />
    </Frame>
  </Step>
</Steps>

## Duplicate a media folder

Duplicating gives you a second folder with the same photos, for example a watermarked copy for proofing.

<Steps>
  <Step title="Choose Duplicate">
    In the folder menu, click **Duplicate**.
  </Step>
  <Step title="Name the copy">
    In **Name**, enter a name for the new folder.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-duplicate-1.png" alt="Duplicate media folder dialog with an empty Name field and Watermark" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-duplicate-1-dark.png" alt="Duplicate media folder dialog with an empty Name field and Watermark" />
    </Frame>
  </Step>
  <Step title="Choose a watermark">
    Under **Watermark**, pick a watermark for the copy, or leave it empty.
  </Step>
  <Step title="Duplicate the folder">
    Click **Duplicate folder**. Shootstack copies the photos into the new folder, which appears at the end of the grid.
  </Step>
</Steps>

<Note>
You can duplicate a folder with up to 500 photos. For a larger one, create a new folder and [copy the photos](/guides/media-folders/organize) over in batches.
</Note>

## Delete a media folder

<Warning>
Deleting a media folder also deletes every photo inside it. This can't be undone.
</Warning>

<Steps>
  <Step title="Open the folder menu">
    Right-click the folder card, or hover the folder in the sidebar and click **⋯**.
  </Step>
  <Step title="Choose Delete">
    Click **Delete**.
  </Step>
  <Step title="Confirm">
    In **Delete folder**, click **Delete**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-delete-1.png" alt="Delete folder dialog with the warning and the Delete button" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-delete-1-dark.png" alt="Delete folder dialog with the warning and the Delete button" />
    </Frame>
  </Step>
</Steps>

## Inside a media folder

- [Upload photos](/guides/media-folders/upload): add photos from your computer.
- [Sort photos](/guides/media-folders/sort): put them in the order your clients should see.
- [View photos](/guides/media-folders/view): find one photo and check its file details.
- [Download photos](/guides/media-folders/download): save a file back to your computer.
- [Organize photos](/guides/media-folders/organize): copy, move, or delete photos.

Your clients never see a media folder directly. Add the folder to a gallery, then send the gallery out with a gallery share.
