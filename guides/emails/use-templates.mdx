Email templates help you reuse a message across gallery shares. While composing an email, you can insert a saved message or save the one you're writing for another time.

## Insert a template

Start with an empty message. Once you type in the body, the template picker is no longer shown.

<Steps>
  <Step title="Open the template picker">
    Click **Insert email template** below the message body.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/emails/use-templates-insert-1.webp" alt="Email composer with Insert email template below the message body" />
      <img className="hidden dark:block" src="/assets/images/guides/emails/use-templates-insert-1-dark.webp" alt="Email composer with Insert email template below the message body" />
    </Frame>
  </Step>
  <Step title="Choose a template">
    Pick the message you want to use. Shootstack fills the email body and leaves your subject as it was.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/emails/use-templates-insert-2.webp" alt="Template picker showing saved messages to choose from" />
      <img className="hidden dark:block" src="/assets/images/guides/emails/use-templates-insert-2-dark.webp" alt="Template picker showing saved messages to choose from" />
    </Frame>
  </Step>
</Steps>

## Save a message as a template

Save the subject and body while you're composing if you'll use them again.

<Steps>
  <Step title="Open the save dialog">
    Below the message body, click **Save as email template**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/emails/use-templates-save-1.webp" alt="Email composer with Save as email template below the message body" />
      <img className="hidden dark:block" src="/assets/images/guides/emails/use-templates-save-1-dark.webp" alt="Email composer with Save as email template below the message body" />
    </Frame>
  </Step>
  <Step title="Review the template">
    The email's subject fills **Title**, and its body fills **Content**. Edit either field if you want to change what the template saves.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/emails/use-templates-save-2.webp" alt="Save email template dialog with Title and Content fields" />
      <img className="hidden dark:block" src="/assets/images/guides/emails/use-templates-save-2-dark.webp" alt="Save email template dialog with Title and Content fields" />
    </Frame>
  </Step>
  <Step title="Save the template">
    In **Save email template**, click **Save template**. The email composer stays open so you can continue writing or send the message.
  </Step>
</Steps>

The template body holds up to 3,000 text characters. Formatting can take up extra space; if the editor warns you, remove some formatting before saving.
