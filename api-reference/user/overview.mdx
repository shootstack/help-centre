The User API lets you retrieve and update the currently authenticated user's profile information.

## Progress

| Endpoint | Method | Status |
| -------- | ------ | ------ |
| `/users/me` | GET | <Badge icon="circle-check" size="sm" color="green">Done</Badge> |
| `/users/me` | PATCH | <Badge icon="circle-check" size="sm" color="green">Done</Badge> |

## Rules

| Rule | Value |
| ---- | ----- |
| Max users | 5,000 per workspace |
| Data retention | 30 days after deletion |
| Dispute strikes | 2 max |
| Spam strikes | 2 max |

## User object

| Field | Type | Description |
| ----- | ---- | ----------- |
| `id` | string | Unique identifier for the user |
| `email` | string | The user's email address |
| `firstName` | string | The user's first name |
| `lastName` | string | The user's last name |
| `timezone` | string | IANA timezone identifier |
| `locale` | string | ISO 3166-1 alpha-2 country code for locale |
| `country` | string | ISO 3166-1 alpha-2 country code |
| `isOnboarded` | boolean | Whether the user has completed onboarding |
| `profilePicture` | object \| null | Profile picture metadata |
