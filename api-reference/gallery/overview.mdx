---
title: Overview
description: Manage galleries within a project
---

The Gallery API lets you create, retrieve, update, and delete galleries. Galleries belong to a project and provide a customizable viewing experience for sharing photos with clients.

## Progress

| Endpoint | Method | Status |
| -------- | ------ | ------ |
| `/galleries` | POST | <Badge size="sm" color="green">Done</Badge> |
| `/galleries/:gallery_id` | GET | <Badge size="sm" color="green">Done</Badge> |
| `/galleries/:gallery_id` | PATCH | <Badge size="sm" color="green">Done</Badge> |
| `/galleries/:gallery_id` | DELETE | <Badge size="sm" color="green">Done</Badge> |
| `/galleries/:gallery_id/photos` | GET | <Badge size="sm" color="green">Done</Badge> |
| `/galleries/:gallery_id/photo-folders` | PATCH | <Badge size="sm" color="green">Done</Badge> |
| `/galleries/:gallery_id/cover` | PATCH | <Badge size="sm" color="green">Done</Badge> |

## Rules

| Rule | Value |
| ---- | ----- |
| Max photo folders | 25 per gallery |
| Max extra covers | 9 per gallery |
| Grid spacing | 0–100 (default 10) |

## Gallery object

| Field | Type | Description |
| ----- | ---- | ----------- |
| `id` | string | Unique identifier for the gallery |
| `projectId` | string | ID of the parent project |
| `name` | string | The gallery name |
| `cover` | object \| null | Cover image metadata |
| `coverTemplateId` | string \| null | Cover template ID (only on retrieve) |
| `colorPaletteId` | string \| null | Color palette ID (only on retrieve) |
| `fontId` | string \| null | Font ID (only on retrieve) |
| `photoFolderIds` | string[] | IDs of photo folders linked to this gallery (only on retrieve) |
| `extraCovers` | object[] | Additional cover images (only on retrieve) |
| `theme` | string | Gallery color theme (only on retrieve) |
| `coverTitle` | string \| null | Title displayed on the gallery cover (only on retrieve) |
| `coverSubTitle` | string \| null | Subtitle displayed on the gallery cover (only on retrieve) |
| `intro` | string \| null | Introduction text for the gallery (only on retrieve) |
| `gridLayout` | string | Photo grid layout style (only on retrieve) |
| `gridPhotoSize` | string | Photo size in the grid (only on retrieve) |
| `gridPhotoSpacing` | integer \| null | Spacing between photos in the grid (only on retrieve) |
| `updatedAt` | string | ISO 8601 timestamp |
| `createdAt` | string | ISO 8601 timestamp |
