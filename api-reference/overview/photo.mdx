---
title: Overview
description: Manage photos within a photo folder
---

The Photo API lets you list, retrieve, upload, download, and delete photos. Photos belong to a photo folder and support batch uploads with duplicate handling, EXIF metadata extraction, and web-optimized versions.

## Progress

| Endpoint | Method | Status |
| -------- | ------ | ------ |
| `/photos` | GET | <Badge icon="circle-check" size="sm" color="green">Done</Badge> |
| `/photos/:photo_id` | GET | <Badge icon="circle-check" size="sm" color="green">Done</Badge> |
| `/photos/:photo_id` | DELETE | <Badge icon="circle-check" size="sm" color="green">Done</Badge> |
| `/photos/upload` | POST | <Badge icon="circle-check" size="sm" color="green">Done</Badge> |
| `/photos/:photo_id/download` | POST | <Badge icon="circle-check" size="sm" color="green">Done</Badge> |

## Rules

| Rule | Value |
| ---- | ----- |
| Max file size | 100 MB |
| Max width | 15,000 px |
| Max height | 15,000 px |
| Max web width | 2,048 px |
| Max web height | 2,048 px |
| Max upload batch | 50 per request |
| Max filename length | 100 characters |

## Photo object

| Field | Type | Description |
| ----- | ---- | ----------- |
| `id` | string | Unique identifier for the photo |
| `sourceKey` | string | Storage key for the original photo |
| `status` | string | Processing status |
| `name` | string | Original filename |
| `contentType` | string | MIME type of the photo |
| `width` | integer | Original image width in pixels |
| `height` | integer | Original image height in pixels |
| `size` | integer | Original file size in bytes |
| `webWidth` | integer | Web-optimized width in pixels |
| `webHeight` | integer | Web-optimized height in pixels |
| `webSize` | integer | Web-optimized file size in bytes |
| `creationDate` | string | Photo creation date from EXIF data |
| `uploadDate` | string | Date the photo was uploaded |
| `exif` | object | EXIF metadata (only on retrieve) |
| `exif.image` | object | Image info (`colorSpace`, `resolution`) |
| `exif.camera` | object | Camera info (`make`, `model`) |
| `exif.exposure` | object | Exposure info (`aperture`, `shutterSpeed`, `iso`) |
| `exif.lens` | object | Lens info (`focalLength`, `focalLength35mm`, `model`) |
