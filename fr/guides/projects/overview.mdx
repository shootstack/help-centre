Un projet regroupe tout ce qui concerne une séance photo, du premier import à la galerie que reçoit votre client : dossiers médias, galeries, liens de galerie, tâches et notes.

Ouvrez **Projets** dans le menu de votre espace de travail pour voir tous les projets de cet espace. Chaque carte affiche sa photo de couverture, son statut et le nombre de dossiers et de galeries.

## Créer un projet

Créez un projet dès qu’une séance photo est réservée. Vous aurez ainsi un endroit pour vos tâches et vos notes avant l’arrivée des photos.

<Steps>
  <Step title="Ouvrir Projets">
    Dans le menu de votre espace de travail, cliquez sur **Projets**.
  </Step>
  <Step title="Démarrer un nouveau projet">
    Cliquez sur **Nouveau**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/projects/overview-create-1.webp" alt="En-tête de la page Projets avec le bouton Nouveau" />
      <img className="hidden dark:block" src="/assets/images/guides/projects/overview-create-1-dark.webp" alt="En-tête de la page Projets avec le bouton Nouveau" />
    </Frame>
  </Step>
  <Step title="Nommer le projet">
    Dans **Nom**, saisissez le nom du projet, par exemple le nom de votre client et la date.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/projects/overview-create-2.webp" alt="Fenêtre Créer un projet avec le champ Nom" />
      <img className="hidden dark:block" src="/assets/images/guides/projects/overview-create-2-dark.webp" alt="Fenêtre Créer un projet avec le champ Nom" />
    </Frame>
  </Step>
  <Step title="Créer le projet">
    Cliquez sur **Créer un projet**. Shootstack ouvre le nouveau projet dans l’onglet **Contenu**, prêt à accueillir votre premier dossier média.
  </Step>
</Steps>

## Ouvrir un projet

Cliquez sur une carte de projet pour l’ouvrir dans l’onglet **Contenu**. Cliquez sur le X en haut à gauche pour revenir à **Projets**.

## Renommer un projet

La plupart des modifications se font dans le menu **⋯** du projet. Faites un clic droit sur la carte du projet ou cliquez sur **⋯** sur la carte. Dans un projet ouvert, cliquez sur **⋯** à côté de son nom.

<Steps>
  <Step title="Choisir Renommer">
    Dans le menu du projet, cliquez sur **Renommer**.
  </Step>
  <Step title="Saisir le nouveau nom">
    Saisissez le nouveau nom, puis cliquez sur **Renommer le projet en** pour confirmer.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/projects/overview-rename-1.webp" alt="Fenêtre de renommage avec l’option Renommer le projet en" />
      <img className="hidden dark:block" src="/assets/images/guides/projects/overview-rename-1-dark.webp" alt="Fenêtre de renommage avec l’option Renommer le projet en" />
    </Frame>
  </Step>
</Steps>

## Définir la photo de couverture

La photo de couverture apparaît sur la carte du projet. Choisissez-en une qui vous permet de reconnaître la séance photo au premier coup d’œil.

Ouvrez le projet et, en haut de la barre latérale de l’onglet **Contenu**, cliquez sur **Choisir une photo**. Si le projet n’a pas encore de photo de couverture, vous pouvez aussi déposer une photo sur **Importer une photo de couverture**.

<Frame>
  <img className="dark:hidden block" src="/assets/images/guides/projects/overview-cover-1.webp" alt="Barre latérale de Contenu dans un projet avec le bouton Choisir une photo" />
  <img className="hidden dark:block" src="/assets/images/guides/projects/overview-cover-1-dark.webp" alt="Barre latérale de Contenu dans un projet avec le bouton Choisir une photo" />
</Frame>

Si la carte coupe la partie de la photo que vous souhaitez montrer, ouvrez le menu de la carte sur **Projets** et cliquez sur **Modifier le point focal**.

Faites glisser la photo jusqu’à ce que cette partie soit visible. La modification s’enregistre pendant le déplacement. Cliquez sur **Terminer** pour fermer.

## Rechercher des projets

Quand vous avez beaucoup de projets, il est plus rapide de les rechercher que de faire défiler la page. Sur **Projets**, cliquez sur l’icône de recherche dans l’en-tête ou appuyez sur **/**, puis saisissez au moins deux caractères du nom.

## Supprimer un projet

<Warning>
Supprimer un projet supprime aussi toutes ses photos et ses galeries. Cette action ne peut pas être annulée.
</Warning>

<Steps>
  <Step title="Ouvrir le menu du projet">
    Sur **Projets**, ouvrez le menu **⋯** de la carte du projet. Dans un projet ouvert, ouvrez le menu **⋯** à côté du nom du projet.
  </Step>
  <Step title="Choisir Supprimer">
    Cliquez sur **Supprimer**.
  </Step>
  <Step title="Confirmer">
    Dans **Supprimer le projet**, cliquez sur **Supprimer**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/projects/overview-delete-1.webp" alt="Fenêtre Supprimer le projet avec le bouton Supprimer" />
      <img className="hidden dark:block" src="/assets/images/guides/projects/overview-delete-1-dark.webp" alt="Fenêtre Supprimer le projet avec le bouton Supprimer" />
    </Frame>
  </Step>
</Steps>

## Dans un projet

Un projet comporte cinq onglets. L’essentiel du travail se fait dans le premier.

- **Contenu** : les dossiers médias et les galeries de cette séance photo. C’est ici que vous importez les photos.
- **Liens de galerie** : les liens que vous avez envoyés à vos clients.
- **Tâches** : les choses à faire pour cette séance photo.
- **Notes** : les notes pour cette séance photo.
- **Activité** : ce qui s’est passé dans ce projet et quand.
