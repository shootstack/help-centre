Un modèle de notes contient du texte que vous réutilisez, comme une liste de prises de vue ou un questionnaire, pour éviter de le retaper à chaque séance photo. Créez-le une fois dans **Modèles**, puis insérez-le dans une note vide quand vous en avez besoin.

## Créer un modèle

<Steps>
  <Step title="Ouvrir Modèles">
    Dans le menu de votre espace de travail, cliquez sur **Notes**, puis ouvrez l’onglet **Modèles**.
  </Step>
  <Step title="Créer un nouveau modèle">
    Cliquez sur **Nouveau**. Si votre espace de travail ne contient pas encore de modèles, cliquez plutôt sur **Créer un modèle**. Une carte de modèle apparaît dans la liste.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/templates-create-1.webp" alt="En-tête de Modèles avec le bouton Nouveau" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/templates-create-1-dark.webp" alt="En-tête de Modèles avec le bouton Nouveau" />
    </Frame>
  </Step>
</Steps>

Pour trouver un modèle dans **Modèles**, cliquez sur l’icône de recherche en haut ou appuyez sur **/**, puis saisissez au moins deux caractères.

<Frame>
  <img className="dark:hidden block" src="/assets/images/guides/notes/templates-create-2.webp" alt="Recherche dans Modèles avec le champ Rechercher des modèles..." />
  <img className="hidden dark:block" src="/assets/images/guides/notes/templates-create-2-dark.webp" alt="Recherche dans Modèles avec le champ Rechercher des modèles..." />
</Frame>

## Ouvrir un modèle

Cliquez sur une carte de modèle pour ouvrir **Modifier le modèle**. Vous pouvez aussi faire un clic droit sur la carte, ou cliquer sur **⋯** sur celle-ci, puis choisir **Ouvrir**.

Un modèle a un titre et un contenu. Mettez le contenu en forme comme celui d’une note. Voir [Rédiger une note](/fr/guides/notes/write).

Le contenu peut contenir jusqu’à 3000 caractères de texte ; raccourcissez-le si vous atteignez la limite.

<Frame>
  <img className="dark:hidden block" src="/assets/images/guides/notes/templates-open-1.webp" alt="Fenêtre Modifier le modèle avec le titre et le contenu" />
  <img className="hidden dark:block" src="/assets/images/guides/notes/templates-open-1-dark.webp" alt="Fenêtre Modifier le modèle avec le titre et le contenu" />
</Frame>

Par défaut, la liste des modèles est triée par **Date de création** dans l’ordre **Décroissant**. Cliquez sur **Tri par** pour changer le tri. Choisissez un champ :

- **Titre**
- **Dernière mise à jour**
- **Date de création**

Choisissez ensuite **Croissant** ou **Décroissant**.

## Insérer un modèle

**Insérer un modèle de note** s’affiche uniquement lorsque le contenu de la note est vide.

<Steps>
  <Step title="Ouvrir une note vide">
    Ouvrez une note qui n’a pas encore de contenu.
  </Step>
  <Step title="Choisir un modèle">
    Sous **Modèles de note**, cliquez sur **Insérer un modèle de note**, puis choisissez un modèle. Shootstack remplit la note vide avec le contenu du modèle.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/templates-insert-1.webp" alt="Modifier la note avec Insérer un modèle de note sous Modèles de note" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/templates-insert-1-dark.webp" alt="Modifier la note avec Insérer un modèle de note sous Modèles de note" />
    </Frame>
  </Step>
</Steps>

## Enregistrer une note comme modèle

Transformez une note terminée en modèle à réutiliser lors de la prochaine séance photo.

<Steps>
  <Step title="Ouvrir la note">
    Ouvrez la note que vous voulez enregistrer.
  </Step>
  <Step title="Enregistrer la note comme modèle">
    Sous **Modèles de note**, cliquez sur **Enregistrer comme modèle de note**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/templates-save-1.webp" alt="Modifier la note avec Enregistrer comme modèle de note sous Modèles de note" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/templates-save-1-dark.webp" alt="Modifier la note avec Enregistrer comme modèle de note sous Modèles de note" />
    </Frame>
  </Step>
  <Step title="Modifier le titre et le contenu">
    Dans **Enregistrer le modèle de note**, les champs sont préremplis avec le titre et le contenu de la note. Modifiez **Titre** ou **Contenu** si vous voulez un texte différent.
  </Step>
  <Step title="Enregistrer le modèle">
    Cliquez sur **Enregistrer le modèle**.
  </Step>
</Steps>

## Supprimer un modèle

<Warning>
Supprimer un modèle le retire de votre espace de travail. Cette action est irréversible.
</Warning>

<Steps>
  <Step title="Ouvrir le menu du modèle">
    Dans **Modèles**, faites un clic droit sur la carte du modèle, ou cliquez sur **⋯** sur celle-ci.
  </Step>
  <Step title="Choisir Supprimer">
    Choisissez **Supprimer**.
  </Step>
  <Step title="Confirmer">
    Dans **Supprimer le modèle de note**, cliquez sur **Supprimer**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/templates-delete-1.webp" alt="Fenêtre Supprimer le modèle de note avec le bouton Supprimer" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/templates-delete-1-dark.webp" alt="Fenêtre Supprimer le modèle de note avec le bouton Supprimer" />
    </Frame>
  </Step>
</Steps>
