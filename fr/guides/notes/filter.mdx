Quand votre liste de notes s’allonge, filtrez-la par date pour retrouver les notes récentes, ou triez la liste **Notes** pour la parcourir.

Ouvrez **Notes** dans le menu de votre espace de travail pour filtrer et trier toutes les notes. L’onglet **Notes** d’un projet ou d’un contact n’a pas de filtre ni de tri.

## Filtrer les notes

Affichez par exemple uniquement les notes que vous avez créées **Cette semaine** ou mises à jour **Ce mois-ci**.

<Steps>
  <Step title="Ouvrir le filtre">
    Dans **Notes**, cliquez sur **Filtre** dans la barre d’outils.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/filter-filter-1.webp" alt="Barre d’outils de Notes avec le bouton Filtre" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/filter-filter-1-dark.webp" alt="Barre d’outils de Notes avec le bouton Filtre" />
    </Frame>
  </Step>
  <Step title="Choisir les notes à afficher">
    Choisissez **Date de création** ou **Date de mise à jour**, puis une période. Choisissez **Cette semaine** ou **Ce mois-ci** pour une période plus courte. Pour une période plus longue, choisissez **Ce trimestre** ou **Cette année**. La liste affiche uniquement les notes correspondantes.
  </Step>
  <Step title="Effacer le filtre">
    Cliquez sur **Effacer les filtres** pour retrouver toutes les notes.
  </Step>
</Steps>

## Trier les notes

Un nouvel espace de travail trie les notes par **Dernière mise à jour**, dans l’ordre **Décroissant**, pour afficher les modifications récentes en premier. Pour changer le tri, cliquez sur **Tri par** dans la barre d’outils. Choisissez un champ :

- **Titre**
- **Dernière mise à jour**
- **Date de création**

Choisissez ensuite **Croissant** ou **Décroissant**.

Les modèles de notes ont leur propre tri. Voir [Modèles de notes](/fr/guides/notes/templates).
