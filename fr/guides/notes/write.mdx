Ouvrez une note et rédigez son contenu, par exemple une liste de prises de vue, une demande d’un client ou des notes pour la livraison que vous pourrez transmettre plus tard.

## Mettre la note en forme

Dans **Modifier la note**, cliquez sur **Rédigez votre note...**, puis rédigez votre texte.

Choisissez une taille de texte dans la barre d’outils :

- **Titre**
- **Titre**
- **Sous-titre**
- **Corps du texte**

Les boutons avec une icône permettent de :

- mettre le texte en gras, en italique, le souligner ou le barrer ;
- annuler ou rétablir une action ;
- ajouter un emoji ;
- insérer un saut de ligne.

<Note>
Une note peut contenir jusqu’à 3000 caractères de texte. La mise en forme peut compter dans cette limite, même si le compteur ne l’indique pas. Si vous atteignez la limite, raccourcissez ou simplifiez la note.
</Note>

## Ajouter un lien

<Steps>
  <Step title="Ouvrir les options du lien">
    Dans la barre d’outils, cliquez sur l’icône de lien.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/write-link-1.webp" alt="Modifier la note avec la fenêtre Lien ouverte" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/write-link-1-dark.webp" alt="Modifier la note avec la fenêtre Lien ouverte" />

  </Step>
  <Step title="Saisir le lien">
    Dans **Lien**, saisissez l’URL dans **Saisissez l’URL du lien**. Vous pouvez ajouter du texte dans **Saisissez le texte du lien (facultatif)**.
  </Step>
  <Step title="Ajouter le lien">
    Cliquez sur **Insérer**. Si vous avez déjà sélectionné un lien, cliquez sur **Mettre à jour**.
  </Step>
</Steps>

## Ajouter une liste

Dans la barre d’outils, ouvrez le menu des listes et choisissez **Liste à puces** ou **Liste numérotée**. Pour une liste de tâches à cocher, choisissez **Liste de tâches**. Choisissez **Sans liste** pour désactiver la liste.

## Exporter un PDF

En bas de **Modifier la note**, cliquez sur **Exporter en PDF**. Le téléchargement commence tout de suite.

Le nom du fichier reprend le titre de la note, ou `note.pdf` si le titre est vide. Si un projet ou un contact est associé à la note, il apparaît dans le PDF.
