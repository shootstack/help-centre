Une note vous permet de consigner les détails d’une séance photo, comme une liste de prises de vue, une demande d’un client ou des notes pour la livraison. Associez chaque note à un projet ou à un contact pour la retrouver quand vous en avez besoin.

Ouvrez **Notes** dans le menu de votre espace de travail pour voir toutes les notes de cet espace.

## Créer une note

Notez les détails tant que vous avez encore la séance photo en tête. Vous pouvez associer la note à un projet ou à un contact.

<Steps>
  <Step title="Ouvrir Notes">
    Dans le menu de votre espace de travail, cliquez sur **Notes**.
  </Step>
  <Step title="Créer une nouvelle note">
    Cliquez sur **Nouvelle**. Si votre espace de travail ne contient pas encore de notes, cliquez sur **Créer une note**. Une carte de note apparaît dans la liste.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/overview-create-1.webp" alt="En-tête de la page Notes avec le bouton Nouvelle" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/overview-create-1-dark.webp" alt="En-tête de la page Notes avec le bouton Nouvelle" />
    </Frame>
  </Step>
</Steps>

## Ouvrir une note

Cliquez sur une carte de note pour ouvrir **Modifier la note**. Vous pouvez aussi cliquer sur **⋯** sur la carte ou faire un clic droit dessus, puis choisir **Ouvrir**.

## Nommer une note

Dans **Modifier la note**, cliquez sur **Note sans titre** et saisissez un titre. Shootstack enregistre vos modifications pendant que vous écrivez.

  <img className="dark:hidden block" src="/assets/images/guides/notes/overview-name-1.webp" alt="Fenêtre Modifier la note avec le texte indicatif Note sans titre dans le champ du titre" />

## Associer un projet ou un contact

<Steps>
  <Step title="Ouvrir la note">
    Cliquez sur la carte de la note ou ouvrez le menu **⋯** et cliquez sur **Ouvrir**.
  </Step>
  <Step title="Choisir un projet ou un contact">
    Cliquez sur **Sélectionnez un projet** ou **Sélectionnez un contact**, puis faites votre choix. Vous pouvez retirer le projet ou le contact de la note si vous n’en avez plus besoin.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/overview-link-1.webp" alt="Fenêtre Modifier la note avec Sélectionnez un projet et Sélectionnez un contact" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/overview-link-1-dark.webp" alt="Fenêtre Modifier la note avec Sélectionnez un projet et Sélectionnez un contact" />
    </Frame>
  </Step>
</Steps>

## Rechercher des notes

Sur **Notes**, cliquez sur l’icône de recherche dans l’en-tête ou appuyez sur **/**, puis saisissez au moins deux caractères. L’onglet **Notes** d’un projet ou d’un contact ne propose pas de recherche.

## Supprimer une note

<Warning>
Supprimer une note la retire de votre espace de travail. Cette action ne peut pas être annulée.
</Warning>

<Steps>
  <Step title="Ouvrir le menu de la note">
    Dans l’onglet **Notes**, ouvrez le menu **⋯** de la carte ou faites un clic droit sur la carte.
  </Step>
  <Step title="Choisir Supprimer">
    Cliquez sur **Supprimer**.
  </Step>
  <Step title="Confirmer">
    Dans **Supprimer la note**, cliquez sur **Supprimer**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/notes/overview-delete-1.webp" alt="Fenêtre Supprimer la note avec le bouton Supprimer" />
      <img className="hidden dark:block" src="/assets/images/guides/notes/overview-delete-1-dark.webp" alt="Fenêtre Supprimer la note avec le bouton Supprimer" />
    </Frame>
  </Step>
</Steps>

## Dans un projet ou un contact

Les notes associées apparaissent aussi dans l’onglet **Notes** d’un projet ou l’onglet **Notes** d’un contact. Cliquez sur **Nouvelle** dans cet onglet pour ajouter une note. Sur un écran étroit, seule l’icône plus apparaît.

Le projet ou le contact est déjà sélectionné, mais vous pouvez encore le changer ou le retirer. Consultez [Projets](/fr/guides/projects/overview) et [Contacts](/fr/guides/contacts/overview).
