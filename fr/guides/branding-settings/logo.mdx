Votre logo aide les clients à reconnaître votre activité de photographe dans les galeries partagées. Importez des versions pour les fonds clairs et sombres afin que le logo reste lisible.

## Importer un logo pour les fonds clairs

<Steps>
  <Step title="Ouvrir le menu de l’espace de travail">
    Cliquez sur le nom de l’espace de travail en haut de la barre latérale de l’application.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/branding-settings/logo-open-1.webp" alt="Menu de l’espace de travail avec Identité visuelle en surbrillance" />
      <img className="hidden dark:block" src="/assets/images/guides/branding-settings/logo-open-1-dark.webp" alt="Menu de l’espace de travail avec Identité visuelle en surbrillance" />
    </Frame>
  </Step>
  <Step title="Ouvrir les paramètres d’identité visuelle">
    Cliquez sur **Identité visuelle**.
  </Step>
  <Step title="Ouvrir l’onglet Logo">
    Cliquez sur **Logo** pour choisir la version à importer.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/branding-settings/logo-open-2.webp" alt="Identité visuelle avec l’onglet Logo et deux cartes de logo" />
      <img className="hidden dark:block" src="/assets/images/guides/branding-settings/logo-open-2-dark.webp" alt="Identité visuelle avec l’onglet Logo et deux cartes de logo" />
    </Frame>
  </Step>
  <Step title="Lancer l’importation">
    Dans la carte **Logo**, cliquez sur **Importer un logo**.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/branding-settings/logo-light-1.webp" alt="Carte Logo avec le bouton Importer un logo" />
      <img className="hidden dark:block" src="/assets/images/guides/branding-settings/logo-light-1-dark.webp" alt="Carte Logo avec le bouton Importer un logo" />
    </Frame>
  </Step>
  <Step title="Choisir votre logo">
    Choisissez un fichier JPG/JPEG, PNG ou WebP sur votre ordinateur. Shootstack l’importe tout de suite et l’affiche dans la carte.
  </Step>
</Steps>

Pour un meilleur rendu, utilisez un logo avec un fond transparent.

<Note>
Chaque image originale peut peser jusqu’à 5 MB. Pour un fichier plus volumineux, exportez une copie plus petite avant de l’importer.
</Note>

<Note>
Chaque image originale peut mesurer jusqu’à 2048 pixels de large ou de haut. Redimensionnez une image plus grande avant de l’importer.
</Note>

## Importer un logo pour les fonds sombres

Utilisez une version qui reste lisible sur les fonds sombres et les photos, comme un logo blanc.

<Steps>
  <Step title="Lancer l’importation">
    Dans la carte **Logo pour fonds sombres**, cliquez sur **Importer un logo**.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/branding-settings/logo-dark-1.webp" alt="Carte Logo pour fonds sombres avec le bouton Importer un logo" />
      <img className="hidden dark:block" src="/assets/images/guides/branding-settings/logo-dark-1-dark.webp" alt="Carte Logo pour fonds sombres avec le bouton Importer un logo" />
    </Frame>
  </Step>
  <Step title="Choisir la version pour les fonds sombres">
    Choisissez le fichier sur votre ordinateur. Shootstack l’importe tout de suite et l’affiche dans la carte.
  </Step>
</Steps>

Si votre logo n’apparaît pas, vérifiez la présentation de la galerie. Certains modèles de couverture n’affichent pas de logo.

## Remplacer un logo

<Steps>
  <Step title="Choisir le logo à remplacer">
    Cliquez sur **Importer un logo** dans la carte de la version à modifier.
  </Step>
  <Step title="Choisir le nouveau logo">
    Choisissez le nouveau fichier sur votre ordinateur. Il remplace le logo de cette carte.
  </Step>
</Steps>

## Retirer un logo

<Warning>
Si vous supprimez un logo, cette version est retirée de votre espace de travail. Cette action est irréversible.
</Warning>

<Steps>
  <Step title="Choisir le logo à retirer">
    Cliquez sur **Retirer le logo** dans la carte de la version à retirer.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/branding-settings/logo-remove-1.webp" alt="Carte Logo avec un logo importé et le bouton Retirer le logo" />
      <img className="hidden dark:block" src="/assets/images/guides/branding-settings/logo-remove-1-dark.webp" alt="Carte Logo avec un logo importé et le bouton Retirer le logo" />
    </Frame>
  </Step>
  <Step title="Confirmer">
    Dans **Supprimer le logo**, cliquez sur **Supprimer**. Pour la version destinée aux fonds sombres, la boîte de dialogue s’intitule **Supprimer le logo pour fonds sombres**.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/branding-settings/logo-remove-2.webp" alt="Boîte de dialogue Supprimer le logo avec le bouton Supprimer" />
      <img className="hidden dark:block" src="/assets/images/guides/branding-settings/logo-remove-2-dark.webp" alt="Boîte de dialogue Supprimer le logo avec le bouton Supprimer" />
    </Frame>
  </Step>
</Steps>
