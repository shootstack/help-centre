---
title: Gérer les champs personnalisés des contacts
sidebarTitle: Champs personnalisés
description: Ajoutez des champs personnalisés pour conserver plus d’informations client dans chaque contact de votre espace de travail.
---

Les champs personnalisés permettent de conserver des informations supplémentaires sur vos clients avec leurs coordonnées. Créez un champ une fois pour votre espace de travail, puis renseignez-le pour chaque contact.

## Ouvrir les paramètres des champs

<Steps>
  <Step title="Ouvrir le menu de l’espace de travail">
    Cliquez sur le nom de l’espace de travail en haut de la barre latérale de l’application.
  </Step>
  <Step title="Ouvrir les paramètres de l’espace de travail">
    Cliquez sur **Paramètres de l’espace de travail**.
  </Step>
  <Step title="Ouvrir les champs des contacts">
    Sous **Espace de travail**, développez **Champs personnalisés**. Cliquez sur **Contact**.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/contacts/custom-fields-open-1.webp" alt="Paramètres des champs des contacts avec Contact sélectionné dans la barre latérale et le bouton Créer un champ visible" />
      <img className="hidden dark:block" src="/assets/images/guides/contacts/custom-fields-open-1-dark.webp" alt="Paramètres des champs des contacts avec Contact sélectionné dans la barre latérale et le bouton Créer un champ visible" />
    </Frame>
  </Step>
</Steps>

## Créer un champ

<Steps>
  <Step title="Ajouter un nouveau champ">
    Cliquez sur **Créer un champ**.
  </Step>
  <Step title="Choisir le type de champ">
    Choisissez un **Type** adapté aux informations que vous conservez. Utilisez **Choix unique** pour un seul choix ou **Choix multiple** pour plusieurs.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/contacts/custom-fields-create-1.webp" alt="Fenêtre Créer un champ personnalisé affichant les types de champs" />
      <img className="hidden dark:block" src="/assets/images/guides/contacts/custom-fields-create-1-dark.webp" alt="Fenêtre Créer un champ personnalisé affichant les types de champs" />
    </Frame>
  </Step>
  <Step title="Nommer le champ">
    Dans **Nom**, saisissez un libellé pour l’information, par exemple le lieu préféré d’un client.
  </Step>
  <Step title="Ajouter des choix si nécessaire">
    Pour les champs à choix, cliquez sur **Ajoutez des options...**. Choisissez une couleur, saisissez un nom pour le choix, puis cliquez sur **Ajouter** pour chaque choix.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/contacts/custom-fields-create-2.webp" alt="Options d’un champ personnalisé avec le sélecteur de couleur, le nom du choix et le bouton Ajouter" />
      <img className="hidden dark:block" src="/assets/images/guides/contacts/custom-fields-create-2-dark.webp" alt="Options d’un champ personnalisé avec le sélecteur de couleur, le nom du choix et le bouton Ajouter" />
    </Frame>
  </Step>
  <Step title="Créer le champ">
    Cliquez sur **Créer un champ personnalisé**. Le nouveau champ apparaît dans les fiches de vos contacts et sous forme de colonne dans la liste des contacts.
  </Step>
</Steps>

Le type d’un champ enregistré ne peut pas être modifié. Pour renseigner ses valeurs, consultez [Modifier un contact](/fr/guides/contacts/details#renseigner-les-champs-personnalisés).

<Note>
Un espace de travail peut contenir jusqu’à 25 champs personnalisés pour les contacts. Supprimez un champ dont vous n’avez plus besoin avant d’en créer un autre.
</Note>

## Modifier un champ

<Warning>
Supprimer un choix le retire des contacts qui l’utilisent, mais leurs autres options sélectionnées dans un champ à choix multiple sont conservées. Cette action est irréversible.
</Warning>

<Steps>
  <Step title="Ouvrir le menu du champ">
    Faites un clic droit sur la ligne du champ personnalisé, ou survolez-la et cliquez sur **⋯**, puis choisissez **Mettre à jour**.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/contacts/custom-fields-edit-1.webp" alt="Menu d’un champ personnalisé avec Mettre à jour et Supprimer" />
      <img className="hidden dark:block" src="/assets/images/guides/contacts/custom-fields-edit-1-dark.webp" alt="Menu d’un champ personnalisé avec Mettre à jour et Supprimer" />
    </Frame>
  </Step>
  <Step title="Modifier le champ">
    Dans **Modifier le champ personnalisé**, modifiez le **Nom**. Pour un champ à choix, ajoutez ou supprimez des choix dans **Options**.
  </Step>
  <Step title="Enregistrer les modifications">
    Cliquez sur **Enregistrer les modifications**. Si vous avez supprimé des choix existants, confirmez avec **Supprimer les options** dans la fenêtre de confirmation.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/contacts/custom-fields-remove-1.webp" alt="Confirmation Supprimer les options affichant les choix supprimés et le nombre de contacts concernés" />
      <img className="hidden dark:block" src="/assets/images/guides/contacts/custom-fields-remove-1-dark.webp" alt="Confirmation Supprimer les options affichant les choix supprimés et le nombre de contacts concernés" />
    </Frame>
  </Step>
</Steps>

<Note>
Un champ à choix peut contenir jusqu’à 25 options. Supprimez une option dont vous n’avez plus besoin avant d’en ajouter une autre.
</Note>

## Supprimer un champ

<Warning>
Supprimer un champ personnalisé supprime aussi ses valeurs pour chaque contact de votre espace de travail. Cette action est irréversible.
</Warning>

<Steps>
  <Step title="Ouvrir le menu du champ">
    Faites un clic droit sur la ligne du champ personnalisé, ou survolez-la et cliquez sur **⋯**.
  </Step>
  <Step title="Choisir Supprimer">
    Choisissez **Supprimer**.
  </Step>
  <Step title="Confirmer">
    Dans **Supprimer le champ personnalisé ?**, cliquez sur **Supprimer le champ**.
    <Frame>
      <img className="block dark:hidden" src="/assets/images/guides/contacts/custom-fields-delete-1.webp" alt="Confirmation Supprimer le champ personnalisé affichant le nom du champ, le nombre de contacts concernés et le bouton Supprimer le champ" />
      <img className="hidden dark:block" src="/assets/images/guides/contacts/custom-fields-delete-1-dark.webp" alt="Confirmation Supprimer le champ personnalisé affichant le nom du champ, le nombre de contacts concernés et le bouton Supprimer le champ" />
    </Frame>
  </Step>
</Steps>
