Quand vous avez terminé une partie du travail d’une séance photo, marquez la tâche comme terminée pour garder votre liste de tâches ouvertes à jour. Vous pouvez aussi consulter les tâches terminées quand vous en avez besoin.

## Marquer une tâche comme terminée

Cochez **Terminée** sur la ligne de la tâche. Vous pouvez aussi faire un clic droit sur la ligne ou cliquer sur **⋯** sur la ligne. Cliquez ensuite sur **Marquer comme terminée**.

Pour remettre la tâche dans votre liste de tâches ouvertes, décochez la case ou cliquez sur **Marquer comme non terminée**.

## Afficher les tâches ouvertes ou terminées

Dans **Tâches**, cliquez sur **Tâches ouvertes** pour voir les tâches terminées. Cliquez sur **Tâches terminées** pour revenir aux tâches encore ouvertes.

<Frame>
  <img className="dark:hidden block" src="/assets/images/guides/tasks/complete-show-1.webp" alt="Barre d’outils de Tâches avec le bouton Tâches ouvertes" />
  <img className="hidden dark:block" src="/assets/images/guides/tasks/complete-show-1-dark.webp" alt="Barre d’outils de Tâches avec le bouton Tâches ouvertes" />
</Frame>

Dans un projet ou un contact, l’onglet **Tâches** affiche les tâches dans un même tableau. Elles sont réparties entre les groupes **Ouvertes** et **Terminées**.

Pour filtrer la liste par date ou modifier le tri, consultez [Filtrer et trier les tâches](/fr/guides/tasks/filter).

## Comment les tâches ouvertes sont regroupées

La liste des tâches ouvertes contient trois groupes :

- **Aujourd’hui**
- **À venir**
- **Aucune date d’échéance**

Les tâches en retard restent sous **Aujourd’hui**.

Si la date d’échéance est passée, vous voyez depuis combien de jours la tâche est en retard. Si elle tombe dans les 7 prochains jours, vous voyez le nombre de jours restants ; si elle est plus lointaine, la date s’affiche.

Dans **Tâches**, les tâches terminées apparaissent dans une seule liste.
