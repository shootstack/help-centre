Une longue liste de tâches est difficile à parcourir. Filtrez et triez la liste **Tâches** pour afficher uniquement le travail de cette semaine, de ce mois ou d’une période plus longue.

Ouvrez **Tâches** dans le menu de votre espace de travail pour filtrer et trier toutes les tâches. L’onglet **Tâches** d’un projet ou d’un contact affiche les tâches de ce projet ou de ce contact.

## Filtrer les tâches

Affichez par exemple uniquement les tâches à terminer **Cette semaine**, ou celles que vous avez créées **Ce mois-ci**. Pour alterner entre les tâches ouvertes et terminées, consultez [Terminer une tâche](/fr/guides/tasks/complete).

<Steps>
  <Step title="Ouvrir le filtre">
    Dans **Tâches**, cliquez sur **Filtre** dans la barre d’outils.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/tasks/filter-filter-1.webp" alt="Barre d’outils de Tâches avec le bouton Filtre" />
      <img className="hidden dark:block" src="/assets/images/guides/tasks/filter-filter-1-dark.webp" alt="Barre d’outils de Tâches avec le bouton Filtre" />
    </Frame>
  </Step>
  <Step title="Choisir les tâches à afficher">
    Choisissez un champ de date et une période :

    - Champ de date : **Date d’échéance**, **Date de création** ou **Date de mise à jour**
    - Période : **Cette semaine**, **Ce mois-ci**, **Ce trimestre** ou **Cette année**

    Le tableau affiche uniquement les tâches correspondantes.
  </Step>
  <Step title="Effacer le filtre">
    Cliquez sur **Effacer les filtres** pour retrouver toutes les tâches.
  </Step>
</Steps>

## Trier les tâches

Un nouvel espace de travail trie les tâches par **Date d’échéance**, dans l’ordre **Croissant**, pour afficher d’abord les tâches à venir. Pour changer le tri, cliquez sur **Tri par** dans la barre d’outils. Choisissez un champ :

- **Date d’échéance**
- **Dernière mise à jour**
- **Date de création**

Choisissez ensuite **Croissant** ou **Décroissant**.
