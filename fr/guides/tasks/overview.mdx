Une tâche est une action qu’il vous reste à faire pour une séance photo ou un client, comme un suivi ou une livraison. Gardez-la dans votre liste jusqu’à ce qu’elle soit terminée.

Ouvrez **Tâches** dans le menu de votre espace de travail pour voir toutes les tâches de cet espace.

## Créer une tâche

<Steps>
  <Step title="Ouvrir Tâches">
    Dans le menu de votre espace de travail, cliquez sur **Tâches**.
  </Step>
  <Step title="Démarrer une nouvelle tâche">
    Cliquez sur **Nouvelle**. Si votre espace de travail n’a pas encore de tâches, cliquez sur **Créer une tâche** à la place.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/tasks/overview-create-1.webp" alt="En-tête de la page Tâches avec le bouton Nouvelle" />
      <img className="hidden dark:block" src="/assets/images/guides/tasks/overview-create-1-dark.webp" alt="En-tête de la page Tâches avec le bouton Nouvelle" />
    </Frame>
  </Step>
  <Step title="Décrire le travail">
    Dans **Que faut-il faire ?**, décrivez la tâche.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/tasks/overview-create-2.webp" alt="Fenêtre Créer une tâche avec le texte indicatif Que faut-il faire ?" />
      <img className="hidden dark:block" src="/assets/images/guides/tasks/overview-create-2-dark.webp" alt="Fenêtre Créer une tâche avec le texte indicatif Que faut-il faire ?" />
    </Frame>
  </Step>
  <Step title="Définir une date d’échéance">
    Cliquez sur **Définir la date d’échéance**, puis choisissez une date. Vous pouvez aussi choisir :

    - **Today**
    - **Tomorrow**
    - **Next week**

    Vous ne pouvez pas choisir une date passée.
  </Step>
  <Step title="Créer la tâche">
    Cliquez sur **Créer une tâche**. La tâche apparaît dans la liste.
  </Step>
</Steps>

Pendant la création, vous pouvez aussi cliquer sur **Sélectionnez un projet** ou **Sélectionnez un contact** pour associer la tâche tout de suite.

## Ouvrir une tâche

Cliquez sur la ligne d’une tâche pour ouvrir **Mettre à jour la tâche**. Vous pouvez aussi faire un clic droit sur la ligne ou cliquer sur **⋯** sur la ligne. Cliquez ensuite sur **Ouvrir**.

## Associer un projet ou un contact

<Steps>
  <Step title="Ouvrir la tâche">
    Cliquez sur la ligne de la tâche. Ou cliquez sur **⋯** sur la ligne, puis sur **Ouvrir**.
  </Step>
  <Step title="Choisir un projet ou un contact">
    Cliquez sur **Sélectionnez un projet** ou **Sélectionnez un contact**, puis choisissez-en un. Vous pouvez effacer la date d’échéance ou dissocier le projet ou le contact si vous n’en avez plus besoin.
  </Step>
  <Step title="Enregistrer">
    Cliquez sur **Mettre à jour la tâche**.
  </Step>
</Steps>

## Supprimer une tâche

<Warning>
Supprimer une tâche la retire de votre espace de travail. Cette action ne peut pas être annulée.
</Warning>

<Steps>
  <Step title="Ouvrir le menu de la tâche">
    Dans **Tâches**, faites un clic droit sur la ligne de la tâche ou cliquez sur **⋯** sur la ligne.
  </Step>
  <Step title="Choisir Supprimer">
    Cliquez sur **Supprimer**.
  </Step>
  <Step title="Confirmer">
    Dans **Supprimer la tâche**, cliquez sur **Supprimer**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/tasks/overview-delete-1.webp" alt="Fenêtre Supprimer la tâche avec le bouton Supprimer" />
      <img className="hidden dark:block" src="/assets/images/guides/tasks/overview-delete-1-dark.webp" alt="Fenêtre Supprimer la tâche avec le bouton Supprimer" />
    </Frame>
  </Step>
</Steps>

## Dans un projet ou un contact

L’onglet **Tâches** d’un projet affiche les tâches de ce projet. L’onglet **Tâches** d’un contact fait de même. Cliquez sur **Nouvelle tâche** dans la barre d’outils de l’un de ces onglets pour ajouter une tâche avec le projet ou le contact déjà sélectionné.

Vous pouvez encore changer ou supprimer cette association. Voir [Projets](/fr/guides/projects/overview) et [Contacts](/fr/guides/contacts/overview).
