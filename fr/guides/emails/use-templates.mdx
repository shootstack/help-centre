Les modèles d’e-mail vous permettent de réutiliser un message pour différents liens de galerie. Pendant que vous rédigez un e-mail, vous pouvez insérer un message enregistré ou enregistrer celui que vous écrivez pour le réutiliser plus tard.

## Insérer un modèle

Commencez avec un message vide. Dès que vous saisissez du texte dans le corps du message, le sélecteur de modèles disparaît.

<Steps>
  <Step title="Ouvrir le sélecteur de modèles">
    Sous le corps du message, cliquez sur **Insérer un modèle d’e-mail**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/emails/use-templates-insert-1.webp" alt="Fenêtre de rédaction d’e-mail avec Insérer un modèle d’e-mail sous le corps du message" />
      <img className="hidden dark:block" src="/assets/images/guides/emails/use-templates-insert-1-dark.webp" alt="Fenêtre de rédaction d’e-mail avec Insérer un modèle d’e-mail sous le corps du message" />
    </Frame>
  </Step>
  <Step title="Choisir un modèle">
    Choisissez le message à utiliser. Shootstack remplit le corps de l’e-mail et laisse votre objet inchangé.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/emails/use-templates-insert-2.webp" alt="Sélecteur de modèles avec les messages enregistrés disponibles" />
      <img className="hidden dark:block" src="/assets/images/guides/emails/use-templates-insert-2-dark.webp" alt="Sélecteur de modèles avec les messages enregistrés disponibles" />
    </Frame>
  </Step>
</Steps>

## Enregistrer un message comme modèle

Enregistrez l’objet et le corps du message pendant la rédaction si vous souhaitez les réutiliser.

<Steps>
  <Step title="Ouvrir la fenêtre d’enregistrement">
    Sous le corps du message, cliquez sur **Enregistrer comme modèle d’e-mail**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/emails/use-templates-save-1.webp" alt="Fenêtre de rédaction d’e-mail avec Enregistrer comme modèle d’e-mail sous le corps du message" />
      <img className="hidden dark:block" src="/assets/images/guides/emails/use-templates-save-1-dark.webp" alt="Fenêtre de rédaction d’e-mail avec Enregistrer comme modèle d’e-mail sous le corps du message" />
    </Frame>
  </Step>
  <Step title="Vérifier le modèle">
    L’objet de l’e-mail est repris dans **Titre**, et le corps du message dans **Contenu**. Vous pouvez modifier l’un ou l’autre pour enregistrer autre chose dans le modèle.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/emails/use-templates-save-2.webp" alt="Fenêtre Enregistrer le modèle d’e-mail avec les champs Titre et Contenu" />
      <img className="hidden dark:block" src="/assets/images/guides/emails/use-templates-save-2-dark.webp" alt="Fenêtre Enregistrer le modèle d’e-mail avec les champs Titre et Contenu" />
    </Frame>
  </Step>
  <Step title="Enregistrer le modèle">
    Dans **Enregistrer le modèle d’e-mail**, cliquez sur **Enregistrer le modèle**. La fenêtre de rédaction reste ouverte : vous pouvez continuer à écrire ou envoyer le message.
  </Step>
</Steps>

Le corps d’un modèle peut contenir jusqu’à 3 000 caractères de texte. La mise en forme peut prendre de la place supplémentaire ; si l’éditeur vous avertit, retirez un peu de mise en forme avant d’enregistrer.
