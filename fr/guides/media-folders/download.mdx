Vous avez parfois besoin de récupérer une photo sur votre ordinateur, par exemple pour l’envoyer à un client ou la retoucher. Vous pouvez télécharger le fichier original que vous avez importé ou la version plus légère que Shootstack a créée pour le web.

## Télécharger une photo

Faites un clic droit sur la photo ou cliquez sur **⋯** sur sa carte, puis sur **Télécharger**. Si la photo est ouverte dans la visionneuse, cliquez sur **Télécharger**.

<Note>
Vous pouvez télécharger une photo à la fois. Pour en récupérer plusieurs, téléchargez-les une par une. Vous pouvez toujours les copier, les déplacer ou les supprimer ensemble.
</Note>

## Choisir le fichier

<Steps>
  <Step title="Choisir une version">
    Sous **Choisissez le fichier photo**, laissez **Fichier photo optimisé pour le web** sélectionné pour obtenir une version plus légère, prête pour le web. Ou cliquez sur **Fichier photo original** pour récupérer le fichier que vous avez importé, à sa taille d’origine. Chaque option affiche le nom et la taille du fichier.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/download-choose-1.webp" alt="Fenêtre Télécharger la photo avec l’option Fichier photo optimisé pour le web sélectionnée" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/download-choose-1-dark.webp" alt="Fenêtre Télécharger la photo avec l’option Fichier photo optimisé pour le web sélectionnée" />
    </Frame>
  </Step>
  <Step title="Télécharger la photo">
    Cliquez sur **Télécharger la photo**. Sur un téléphone, vous pouvez enregistrer la photo dans le menu de partage qui s’ouvre.
  </Step>
</Steps>

## Si un téléchargement est bloqué

Votre formule inclut un volume de données mensuel pour les téléchargements. Une fois ce volume épuisé, les téléchargements sont suspendus jusqu’au début du mois suivant.

<Note>
Si la fenêtre **Télécharger la photo** indique que votre volume de données pour les téléchargements de ce mois est épuisé, attendez le mois prochain ou passez à une formule supérieure pour continuer à télécharger.
</Note>
