Un dossier média contient les photos d’une séance. La plupart des photographes créent un dossier par série, par exemple pour les photos de présélection et les versions finales. Une galerie peut ainsi montrer à vos clients exactement les photos qui leur sont destinées.

## Où trouver les dossiers médias

Les dossiers médias appartiennent à un projet. Ouvrez le projet, puis l’onglet **Contenu**. Dans la barre latérale de gauche, cliquez sur **Dossiers médias** pour voir chaque dossier sous forme de carte.

## Créer un dossier média

Créez un dossier chaque fois que vous avez une série de photos à garder ensemble, par exemple les photos de présélection d’une séance.

<Steps>
  <Step title="Ouvrir Dossiers médias">
    Dans l’onglet **Contenu** du projet, cliquez sur **Dossiers médias** dans la barre latérale de gauche.
  </Step>
  <Step title="Créer un nouveau dossier média">
    Cliquez sur **Nouveau**. Si le projet n’a pas encore de dossier, cliquez plutôt sur **Créer un dossier**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-create-1.webp" alt="En-tête de la page Dossiers médias avec le bouton Nouveau" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-create-1-dark.webp" alt="En-tête de la page Dossiers médias avec le bouton Nouveau" />
    </Frame>
  </Step>
  <Step title="Nommer le dossier média">
    Dans **Nom**, saisissez un nom qui vous permettra de reconnaître le dossier plus tard, par exemple la série ou la date.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-create-2.webp" alt="Fenêtre Créer un dossier média avec Nom, Filigrane (facultatif) et Activer le tri manuel" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-create-2-dark.webp" alt="Fenêtre Créer un dossier média avec Nom, Filigrane (facultatif) et Activer le tri manuel" />
    </Frame>
  </Step>
  <Step title="Choisir un filigrane">
    Dans **Filigrane (facultatif)**, choisissez un filigrane s’il s’agit de photos de présélection. Vos clients peuvent les voir dans une galerie, mais ne peuvent pas les télécharger. Laissez ce champ vide pour les photos finales.
  </Step>
  <Step title="Créer le dossier média">
    Cliquez sur **Créer un dossier**. Le nouveau dossier apparaît à la fin de la grille, prêt à accueillir vos photos.
  </Step>
</Steps>

**Activer le tri manuel** est activé pour les nouveaux dossiers. Vous pouvez ainsi faire glisser les photos pour les mettre dans l’ordre de votre choix.

Un dossier avec tri manuel peut contenir jusqu’à 500 photos. Consultez [Trier les photos](/fr/guides/media-folders/sort).

<Note>
Un projet peut contenir jusqu’à 25 dossiers médias.
</Note>

## Ouvrir un dossier média

Cliquez sur la carte du dossier ou sur le dossier dans la barre latérale de gauche. Vous pouvez aussi faire un clic droit sur le dossier et choisir **Ouvrir**.

## Renommer un dossier média

Faites un clic droit sur la carte du dossier ou survolez le dossier dans la barre latérale et cliquez sur **⋯**.

<Steps>
  <Step title="Choisir Renommer">
    Dans le menu du dossier, cliquez sur **Renommer**.
  </Step>
  <Step title="Saisir le nouveau nom">
    Saisissez le nouveau nom, puis cliquez sur **Renommer le dossier en** pour confirmer.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-rename-1.webp" alt="Fenêtre Options avec le nom du dossier et Renommer le dossier en" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-rename-1-dark.webp" alt="Fenêtre Options avec le nom du dossier et Renommer le dossier en" />
    </Frame>
  </Step>
</Steps>

## Dupliquer un dossier média

Dupliquez un dossier pour en créer un second avec les mêmes photos, par exemple une copie avec filigrane pour la présélection.

<Steps>
  <Step title="Choisir Dupliquer">
    Dans le menu du dossier, cliquez sur **Dupliquer**.
  </Step>
  <Step title="Nommer la copie">
    Dans **Nom**, saisissez le nom du nouveau dossier.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-duplicate-1.webp" alt="Fenêtre Dupliquer le dossier média avec le champ Nom vide et Filigrane" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-duplicate-1-dark.webp" alt="Fenêtre Dupliquer le dossier média avec le champ Nom vide et Filigrane" />
    </Frame>
  </Step>
  <Step title="Choisir un filigrane">
    Dans **Filigrane**, choisissez un filigrane pour la copie ou laissez ce champ vide.
  </Step>
  <Step title="Dupliquer le dossier">
    Cliquez sur **Dupliquer le dossier**. Shootstack copie les photos dans le nouveau dossier, qui apparaît à la fin de la grille.
  </Step>
</Steps>

<Note>
Vous pouvez dupliquer un dossier contenant jusqu’à 500 photos. Pour un dossier plus grand, créez-en un nouveau et [copiez les photos](/fr/guides/media-folders/organize) en plusieurs fois.
</Note>

## Supprimer un dossier média

<Warning>
Supprimer un dossier média supprime aussi toutes les photos qu’il contient. Cette action ne peut pas être annulée.
</Warning>

<Steps>
  <Step title="Ouvrir le menu du dossier">
    Faites un clic droit sur la carte du dossier ou survolez le dossier dans la barre latérale et cliquez sur **⋯**.
  </Step>
  <Step title="Choisir Supprimer">
    Cliquez sur **Supprimer**.
  </Step>
  <Step title="Confirmer">
    Dans **Supprimer le dossier**, cliquez sur **Supprimer**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/media-folders/overview-delete-1.webp" alt="Fenêtre Supprimer le dossier avec l’avertissement et le bouton Supprimer" />
      <img className="hidden dark:block" src="/assets/images/guides/media-folders/overview-delete-1-dark.webp" alt="Fenêtre Supprimer le dossier avec l’avertissement et le bouton Supprimer" />
    </Frame>
  </Step>
</Steps>

## Dans un dossier média

- [Importer des photos](/fr/guides/media-folders/upload) : ajouter des photos depuis votre ordinateur.
- [Trier les photos](/fr/guides/media-folders/sort) : mettre les photos dans l’ordre dans lequel vos clients doivent les voir.
- [Afficher les photos](/fr/guides/media-folders/view) : trouver une photo et vérifier les détails de son fichier.
- [Télécharger des photos](/fr/guides/media-folders/download) : enregistrer un fichier sur votre ordinateur.
- [Organiser les photos](/fr/guides/media-folders/organize) : copier, déplacer ou supprimer des photos.

Vos clients ne voient jamais directement un dossier média. Ajoutez le dossier à une galerie, puis envoyez-la avec un lien de galerie.
