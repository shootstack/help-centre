Votre client peut sélectionner les photos qui lui plaisent dans une galerie partagée. Examinez sa sélection, puis copiez les photos dans un dossier média.

Épingler un projet est une autre fonction. Consultez [Favoris](/fr/guides/projects/favorites).

## Autoriser les favoris

Par défaut, un nouveau lien de galerie permet aux clients de sélectionner les photos qui leur plaisent.

<Steps>
  <Step title="Ouvrir Favoris">
    Dans la galerie, cliquez sur **Partager la galerie**, puis sur **Créer un lien**. Cliquez sur **Suivant** jusqu’à l’étape **Favoris**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/gallery-shares/favorites-allow-1.webp" alt="Partager la galerie à l’étape Favoris, avec Autoriser les favoris activé" />
      <img className="hidden dark:block" src="/assets/images/guides/gallery-shares/favorites-allow-1-dark.webp" alt="Partager la galerie à l’étape Favoris, avec Autoriser les favoris activé" />
    </Frame>
  </Step>
  <Step title="Laisser les favoris activés">
    Laissez **Autoriser les favoris** activé pour que votre client puisse cliquer sur **Ajouter aux favoris** sur une photo. Désactivez-le s’il doit seulement regarder les photos.
  </Step>
</Steps>

Pour modifier ce réglage plus tard, ouvrez le lien de galerie dans la liste **Liens de galerie** du projet. Dans **Informations**, ouvrez **Paramètres des favoris**. Les modifications sont enregistrées tout de suite.

## Définir une limite de favoris

Définissez une limite pour obtenir une petite sélection, par exemple les photos que votre client préfère dans une galerie de présélection.

<Steps>
  <Step title="Activer la limite">
    Dans **Favoris**, activez **Limite de photos favorites**. Si vous ne voyez pas ce réglage, activez d’abord **Autoriser les favoris**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/gallery-shares/favorites-limit-1.webp" alt="Paramètres des favoris avec Limite de photos favorites activée et le nombre fixé à 25" />
      <img className="hidden dark:block" src="/assets/images/guides/gallery-shares/favorites-limit-1-dark.webp" alt="Paramètres des favoris avec Limite de photos favorites activée et le nombre fixé à 25" />
    </Frame>
  </Step>
  <Step title="Saisir le nombre">
    Saisissez le nombre maximal de photos qu’un client peut sélectionner. La valeur initiale est 25.
  </Step>
</Steps>

Dans **Informations**, vous saisissez ce nombre dans **Limite de favoris**.

<Note>
Un client peut sélectionner jusqu’à 500 photos comme favoris par lien de galerie, même si **Limite de photos favorites** est désactivée. Pour une limite plus basse, saisissez un nombre de 1 à 500.
</Note>

## Examiner les photos favorites

<Steps>
  <Step title="Ouvrir la liste">
    Sur la page du lien de galerie, ouvrez l’onglet **Favoris**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/gallery-shares/favorites-review-1.webp" alt="Onglet Favoris avec un tableau des photos ajoutées aux favoris" />
      <img className="hidden dark:block" src="/assets/images/guides/gallery-shares/favorites-review-1-dark.webp" alt="Onglet Favoris avec un tableau des photos ajoutées aux favoris" />
    </Frame>
  </Step>
  <Step title="Examiner chaque photo sélectionnée">
Examinez chaque photo et les éventuels commentaires laissés par votre client. Le nom du fichier et le moment où il a sélectionné la photo apparaissent sur la même ligne.
  </Step>
</Steps>

## Copier les favoris dans un dossier

<Steps>
  <Step title="Ouvrir le menu">
    Le menu se trouve dans l’onglet **Favoris**. Cliquez sur **⋯** à côté de **Photos favorites**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/gallery-shares/favorites-copy-1.webp" alt="Menu de la barre d’outils Photos favorites avec Copier dans un dossier" />
      <img className="hidden dark:block" src="/assets/images/guides/gallery-shares/favorites-copy-1-dark.webp" alt="Menu de la barre d’outils Photos favorites avec Copier dans un dossier" />
    </Frame>
  </Step>
  <Step title="Choisir Copier dans un dossier">
    Cliquez sur **Copier dans un dossier**.
  </Step>
  <Step title="Nommer le dossier">
    Dans **Copier dans un dossier**, saisissez un nom de dossier dans **Nom**, par exemple Sélection du client.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/gallery-shares/favorites-copy-2.webp" alt="Fenêtre Copier dans un dossier avec le champ Nom et Copier dans un dossier" />
      <img className="hidden dark:block" src="/assets/images/guides/gallery-shares/favorites-copy-2-dark.webp" alt="Fenêtre Copier dans un dossier avec le champ Nom et Copier dans un dossier" />
    </Frame>
  </Step>
  <Step title="Copier les photos">
    Cliquez sur **Copier dans un dossier**. Shootstack crée dans le projet un dossier média contenant tous les favoris du lien de galerie.
  </Step>
</Steps>

<Note>
Un projet peut contenir jusqu’à 25 dossiers médias. Si le projet est plein, supprimez un dossier dont vous n’avez plus besoin, puis recommencez la copie. Consultez [Dossiers médias](/fr/guides/media-folders/overview).
</Note>
