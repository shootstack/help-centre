Choisissez ce que vos clients peuvent télécharger depuis une galerie partagée et consultez ce qu’ils ont téléchargé. Définissez le code PIN et les limites à l’étape **Téléchargement** lorsque vous créez le lien.

## Exiger un code PIN de téléchargement

Vos clients n’ont à saisir un code PIN que si vous activez **Protection par code PIN**.

<Steps>
  <Step title="Ouvrir Téléchargement">
    Dans la galerie, cliquez sur **Partager la galerie**, puis sur **Créer un lien**. Cliquez sur **Suivant** jusqu’à l’étape **Téléchargement**.
  </Step>
  <Step title="Activer la protection par code PIN">
    Activez **Protection par code PIN**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/gallery-shares/downloads-pin-1.webp" alt="Paramètres de téléchargement avec Protection par code PIN activée" />
      <img className="hidden dark:block" src="/assets/images/guides/gallery-shares/downloads-pin-1-dark.webp" alt="Paramètres de téléchargement avec Protection par code PIN activée" />
    </Frame>
  </Step>
  <Step title="Saisir le code PIN">
    Saisissez un code PIN à 4 chiffres dans les cases qui apparaissent. Vos clients le saisissent dans la fenêtre **Débloquer les téléchargements** avant de télécharger.
  </Step>
</Steps>

## Autoriser le téléchargement de toute la galerie

Un nouveau lien de galerie permet déjà à vos clients de télécharger toute la galerie en une fois. La **Limite de téléchargements de la galerie** est réglée sur 5.

<Steps>
  <Step title="Trouver les téléchargements de la galerie">
    À l’étape **Téléchargement**, repérez **Autoriser le téléchargement de la galerie**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/gallery-shares/downloads-gallery-1.webp" alt="Paramètres de téléchargement avec Autoriser le téléchargement de la galerie activé, Limite de téléchargements de la galerie sur 5, et Fichier original et Fichier optimisé pour le web cochés" />
      <img className="hidden dark:block" src="/assets/images/guides/gallery-shares/downloads-gallery-1-dark.webp" alt="Paramètres de téléchargement avec Autoriser le téléchargement de la galerie activé, Limite de téléchargements de la galerie sur 5, et Fichier original et Fichier optimisé pour le web cochés" />
    </Frame>
  </Step>
  <Step title="Laisser le téléchargement de la galerie activé">
    Laissez **Autoriser le téléchargement de la galerie** activé. Désactivez-le si vos clients ne doivent pas télécharger toute la galerie.
  </Step>
  <Step title="Définir la limite de téléchargements">
    Avec **Limite de téléchargements de la galerie** activée, saisissez le nombre de téléchargements de la galerie autorisés pour ce lien, de 1 à 50.
  </Step>
  <Step title="Choisir les fichiers">
    Sous **Fichiers proposés pour la galerie**, choisissez les versions proposées à vos clients. Décochez **Fichier original** ou **Fichier optimisé pour le web** s’ils ne doivent pas recevoir cette version. Les deux options sont cochées au départ.
  </Step>
</Steps>

<Note>
Un lien de galerie autorise jusqu’à 50 téléchargements de la galerie, même si **Limite de téléchargements de la galerie** est désactivée. Pour en autoriser moins, laissez la limite activée et saisissez un nombre plus bas.
</Note>

## Autoriser les téléchargements de photos

Un nouveau lien de galerie permet déjà à vos clients de télécharger les photos une par une. La **Limite de téléchargements de photos** est désactivée.

<Steps>
  <Step title="Trouver les téléchargements de photos">
    À l’étape **Téléchargement**, repérez **Autoriser le téléchargement des photos**.
    <Frame>
      <img className="dark:hidden block" src="/assets/images/guides/gallery-shares/downloads-photo-1.webp" alt="Paramètres de téléchargement avec Autoriser le téléchargement des photos activé et Limite de téléchargements de photos désactivée" />
      <img className="hidden dark:block" src="/assets/images/guides/gallery-shares/downloads-photo-1-dark.webp" alt="Paramètres de téléchargement avec Autoriser le téléchargement des photos activé et Limite de téléchargements de photos désactivée" />
    </Frame>
  </Step>
  <Step title="Laisser le téléchargement des photos activé">
    Laissez **Autoriser le téléchargement des photos** activé. Désactivez-le si vos clients ne doivent pas enregistrer les photos une par une.
  </Step>
  <Step title="Définir une limite plus basse">
    Activez **Limite de téléchargements de photos** et saisissez le nombre de téléchargements de photos autorisés pour ce lien, de 1 à 500. Il est réglé sur 50 au départ.
  </Step>
  <Step title="Choisir les fichiers">
    Sous **Fichiers proposés pour les photos**, choisissez les versions proposées à vos clients. Décochez **Fichier original** ou **Fichier optimisé pour le web** s’ils ne doivent pas recevoir cette version. Les deux options sont cochées au départ.
  </Step>
</Steps>

<Note>
Un lien de galerie autorise jusqu’à 500 téléchargements de photos, même si **Limite de téléchargements de photos** est désactivée. Activez la limite pour définir un nombre plus bas.
</Note>

Une photo avec un filigrane ne peut pas être téléchargée. Consultez [Dossiers médias](/fr/guides/media-folders/overview).

Pour modifier les paramètres de téléchargement plus tard, ouvrez le lien dans la liste **Liens de galerie** du projet. Dans **Informations**, ouvrez **Paramètres du code PIN de téléchargement** pour modifier le code PIN.

Utilisez **Paramètres de téléchargement de la galerie** ou **Paramètres de téléchargement des photos** pour choisir ce que vos clients peuvent télécharger. Les modifications sont enregistrées tout de suite.

## Consulter l’activité de téléchargement

Ouvrez **Téléchargements de la galerie** ou **Téléchargements de photos** pour voir ce qu’un client a téléchargé et s’il s’agit de la version originale ou web. La préparation d’un téléchargement de la galerie peut prendre un moment.

  <img className="hidden dark:block" src="/assets/images/guides/gallery-shares/downloads-activity-1-dark.webp" alt="Tableau Téléchargements de la galerie avec le type de téléchargement original ou web" />
</Frame>

Ces téléchargements utilisent le volume de données mensuel de votre formule. Une fois ce volume épuisé, attendez le mois prochain ou passez à une formule supérieure.
