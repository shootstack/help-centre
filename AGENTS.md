# Documentation project instructions

## About this project

- This is a documentation site built on [Mintlify](https://mintlify.com)
- Pages are MDX files with YAML frontmatter
- `docs.json` is the Mintlify entry shell. Site settings live in `config/` (`branding.json`, `site.json`, `navigation/`). Favicon, logo, icons, and screenshots live in `assets/`
- The Help Center serves photographers, with three root tabs in `config/navigation/index.json`: Academy (video lessons), Guides (step-by-step guides), and Troubleshooting (question-and-answer articles). Guides lists Introduction as a single page, then one collapsible sidebar `group` per core feature (Projects, Media folders, ...) with an Overview article first; pages live in `guides/<section>/`. Plan a section with the `ss-guides-architecture` skill and write each article with the `ss-guides-article` skill (both in `.agents/skills/`, linked into `.claude/skills/` and `.agents/skills/`). Add Troubleshooting articles to that tab's `pages` list. Add or change an Academy lesson in `snippets/academy-lessons.js`, run `npm run sync-academy`, then write the lesson body. Do not hand-edit the Academy overview list, sidebar times, or Academy page order.
- The diamond-app Help drawer reads a catalog of every photographer article. Run `npm run sync-app-help` after adding a page or changing a title, description, or path; it writes `src/integrations/help-centre/helpCentreArticles.json` in diamond-app (found by id in the workspace `registry.json`, normally `projects/diamond-app`). Which articles each app path shows is picked in diamond-app's `src/integrations/help-centre/helpCentreRoutes.js`, not here.
- Layer conventions live in `.agents/rules/`; the "Agent setup" section at the end of this file lists each rule with its globs. Match the local layer pattern before inventing structure. When you add a top-level folder, script, rule, or skill, update the file layout in `README.md` in the same change.
- Run `npm run dev` (port **3333**) to preview
- Run `npm run validate` and `npm run broken-links` before committing

## Voice and terminology

The reader is a photographer, usually mid-task. These files own the writing, and nothing else restates them:

- Tone of voice (helpful, professional, calm, supportive, natural): the help-centre surface of the Shootstack voice, `teams/marketing/brand/voice/surfaces/help-centre.md` from the workspace root (`../../teams/marketing/brand/voice/surfaces/help-centre.md` from here), owned by support. The single definition, with examples and the standard phrasings every photographer article reuses.
- Copy mechanics (frontmatter, Diamond terminology, bold UI labels, what stays out, components, links): `.agents/rules/help-mdx-copy.md`.
- Page shape per tab: `help-guides.md`, `help-academy.md`, `help-troubleshooting.md`.
- Translation: English is written here. Target languages go through diamond-translate in `tools/translate` — see `help-translations.md`. Page keys, the Mintlify language contract, and `npm run i18n:audit` are the `ss-help-i18n` skill.

Run the `ss-voice-review` skill on every page you write or rewrite.

## Content boundaries

- Customer-facing help only. Do not add OpenAPI specs or endpoint reference pages.
- Link to the Shootstack app from photographer pages. To reach support there, tell the reader to open **Help** and click **Chat with support**. Do not publish support@shootstack.com.
- Do not invent product behavior. If a flow is unclear, ask.

### Translations

Write English here. Follow the help-centre
voice and translation rules (`teams/marketing/brand/voice/surfaces/help-centre.md`, `tools/translate/projects/help-centre/`)
layered over the central voice and the shared translation rules. Paths in
backticks are from the Shootstack workspace root. Pages follow `help-centre.md`.

Page keys, navigation, the Mintlify language contract, and `npm run i18n:audit`
are the [`ss-help-i18n` skill](.agents/skills/ss-help-i18n/SKILL.md).

Do not write Dutch, German, French, or any later language pages, navigation, or
snippets in this repo. help-centre has no languages configured yet. Bold UI
labels in a translation come from diamond-app for that language,
not from a paraphrase written here.

Previews, translated pages, and coverage are
diamond-translate (`tools/translate/AGENTS.md`). When a change adds,
changes, moves, or removes English pages, end with a
`Handoff: copy` block (format in `tools/translate/AGENTS.md`).
